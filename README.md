# すべての存在の幸福を考える

知性と協力と自己超越の哲学。著者 **oopdesc**。制作にAIを使用しています。

この本は、著者が長い苦しみの中で考え続けてきた経験と思索を出発点にしています。誰も配慮から排除せず、避けられる深刻な苦しみを減らし、それぞれが生を選び直せる条件を広げる。その提案を、研究でわかったこと、価値の選択、条件つきの推論、未解決の問いに分けて考えます。
