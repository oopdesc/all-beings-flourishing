# 第23章 对本提案提出反驳

<a id="s2"></a>

## 把幸福当共同目的本身就是支配吗

此反驳重要。有人更重真理、忠诚或创造。外定幸福并强迫全体趋向，本书也可能成为支配思想。

所以不是把所有生活统一为愉悦，而包含本人思考价值、选择、异议的条件。有比一切存在的幸福更合适表述，也应考虑。

要保护的是不把某人的生仅作为他人计划材料。若目的用语阻碍此原则，就须改词。

<a id="s3"></a>

## 只是重述既有思想吗

重视痛苦、公平、自由、相互正当化、重新理解自我，并非本书首创，都有长传统与现代研究。

Scanlon 以理由与正当化讨论彼此义务。[33] Sen 重新审视社会选择中的比较信息。[25] 开放个人同一性的哲学也已有。[34]

不忽视前人、只起新名便称独创。本书工作是在关怀痛苦、更新目的、探索宇宙的脉络中连接已有回答与未知，使读者能用能改。

这种连接未被证明唯一或最优，其价值也可由能否追前提、找错误、继续探究评价。

<a id="s4"></a>

## 对人类合作是否太乐观

有合作可能不同于人人必合作。加害可能不停，对话可能不成立，利益资源权力问题不能全归缺少沟通。

因此善意之外，本书重视防害、限权、责任、救济、退出。让合作者被无限利用，目的无法持续。

但预设全体敌对也可能丢失合作。2026年国际实验中实际合作与预期的落差，有助检验此预设。[37] 不把万能希望寄予单项结果，应看情境证据。

<a id="s5"></a>

## 对不同意关怀理由的人怎么办

我珍视公平痛苦，不保证全体同意。我没有像数学般迫使所有人承认的最终证明。

但可因避免相互伤害、规则可预期、维持关系等其他理由合作。不共享终极哲学，也可能同意具体行动。

仍有分歧时，承认差别并限制加害、保护权利。伦理根本未解不是任意行动许可，仍能讨论社会规则及其正当化。

<a id="s6"></a>

## 一切存在范围是否太广

开始计算未知宇宙、无数未来存在，可能无法决定眼前行动；想象巨大利益也可能冲走当前权利。

本书不采用无证无限利益必重于有限现实伤害的计算，而说明理由，考察可确认生活、迫近严重伤害与不可逆长期影响。

也不自动把增加未来人口或体验总量定为最高目的。仍要问谁的生活改善、如何同意分配。数量不能单独决定个体意义。

<a id="s7"></a>

## 如果思想错了怎么办

可能性始终在。前提可能不当，用语可能太宽而妨碍判断，实践可能意外增负。

此时先处理伤害修正，不为思想名誉牺牲人。重视目的，不等于无论如何守住当前表述。

以书为足场，不只向同方向堆，也包括拆弱处、转往别的足场。不能交付这种自由，就与自我超越不一致。
