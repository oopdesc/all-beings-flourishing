# 第15章 用小模型检验合作

<a id="s2"></a>

## 使用数字的理由与限度

以下把部分哲学转化为前提可见的形式，并非宣称发现新社会定律，而是用虚构小例子解释合作研究中的公共品结构。[43]

数字不是真实幸福测量，也不是实验再现数据，而是追踪计算的假定分值。前提改变，结果也改变。

假设三人共同活动，每人选择投入一个资源单位或不投入。资源增值为两倍，平分给三人。所得减自身投入，称为此处的收益。

<a id="s3"></a>

## 明明全部投入更好却不投入

全体各投一，合计三翻倍为六，每人分二，减投入一，各得一。

无人投入，则无人分得资源，各收益为零。比较两结果，全投对每个人都更好。

但看个人选择，投入一只增加自身分额二的三分之一，即三分之二，成本为一，因此自身收益减少三分之一。

其他两人选择不变时，不投入总多得三分之一。若三人只最大化此种个人收益，就趋向全不投入。对全体更好的结果并不从各自最大化产生。

<a id="s4"></a>

## 例子能说明什么

仅提高计算能力未必产生合作，准确计算私人收益反而导向不合作。问题在利益结构，不在算错。

可以改变条件，如考虑未来关系、保证贡献受回报、在全体同意的条件下建立共同活动。但每种是否有效都需考察。

也须谨慎对待增加信息就能解决的主张。本模型即使完全知情，收益结构也不变。应区分减少行为误判的重要现实场景，与仅靠信息解决不了的利益问题。

<a id="s5"></a>

## 例子不能说明什么

现实人不只按规定收益行动，也可能重视公平、他人、信任和规范。第8章的2026年国际实验报告，在特定条件下很多人选择合作。[37]

虚构三人模型与该实验设计不同，不能用模型说实验错误，也不能用实验说模型计算错误，因为前提对象不同。

这种差别是连接模型现实的研究起点：选择受什么影响，制度改变使哪些行为变化？从理论预测、从观察修正前提，省略往返就不能说仅靠公式解释社会。
