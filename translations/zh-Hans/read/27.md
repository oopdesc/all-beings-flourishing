# 附录C 设计下一步研究

以下为未实施计划例，展示如何可检验。有重叠先读既有研究、判断是否真需复现扩展。写在这里不构成人体研究许可。

<a id="s2"></a>

## 研究共同目的讨论

聚焦共同确认目的、负担、异议渠道怎样改变理解与负担偏斜。可比较同样时长、同样任务说明但无共同确认的程序，明确效果相对何者。

主要指标可为正确说明目的角色的比例，研究前定评分。实际负担分布、参与便利、满意与不利另记。

不只预测变好，而定哪些指标何时变化，也列解释增时却负担不均、少数难发声等失败可能。结果不符就修改共享方式或机制解释。

考虑随机、群体分配、信息传播，样本设计包括效果检测、不利与脱落，提前分主要和探索分析。

<a id="s3"></a>

## 研究对他人的期待与合作

从2026年国际实验读起，考察期待与合作关系。[37] 新情境不把结论当现成宣传词。

提供信息须真实适配，不可为诱导行为伪造合作率。分别测理解、期待、行为变化。

不把不合作者评为道德低劣。实验选择、生活限制、思想赞否不同，数据不未经同意转用于雇用成绩评价。

<a id="s4"></a>

## 让意识假说接近研究

检验主观是否为一，须与替代假说预测不同观察。尚未给差异，就不能称获观察支持。

言语报告表征用于哪些内部过程、理论指标何时稳定，则更具体。[36][39][41] 仍须区分功能研究与确定现象体验。

提研究前，既写发现能说明什么，也写即便发现仍不能说明什么。这句话保护研究与愿望边界。

<a id="s5"></a>

## 报告最低要求

说明问题、事先预测、对象选择、比较、测量、时段、缺失脱落、分析、效果与不确定性、不利、限制，事后改变解释也须记录。

不只报显著结果，保留失败条件。去识别地尽量分享资料分析，不能分享须说明。不把未做计划宣传成成果。

目的不是一项实验裁决伦理真理，而是使别人能核实共同目的转成程序后发生什么。
