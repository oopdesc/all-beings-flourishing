# 第24章 活出下一个问题

<a id="s2"></a>

## 回到最初目的

简述结论：我们可以选择不因他人的幸福离自己遥远就视其无价值。减少可避免严重痛苦，扩大自主生活条件，并合作更新智能、制度与目的。

这不预言所有愿望无矛盾实现，也不宣称发现宇宙最终目的，而是在冲突有限现实中提出保护什么、调查什么、怎样修正。

关心他人不要求消灭自己；共同目的不要求同样生活；提高智能不贬低较弱者；探索宇宙不让当下痛苦后置。

保留四个区别，理想才能保护人，而不只是动员。

<a id="s3"></a>

## 留下什么知识

已有多维幸福测量、合作条件研究、社会选择的数学可能与限度、意识竞争理论比较、观测约束宇宙史等。

但相加不自动完成终极理论，因为对象方法问题各异，连接时须说明中间前提。

想留给读者的不只结论，还包括观察发现、价值选择、有条件推理、未验证想象的边界，使研究进展时知道该改哪里。

<a id="s4"></a>

## 信念也会重生

我的目的信念也非天生完成，而在经历、思考、关系与语言中形成，今后仍可能改变。

能改变不代表当前无意义。可说明当下理由并负责，同时给未来自己与他人重审的自由。

更强 AI 与研究可能促使重写。但作者能力强不自动让新书正确，检查依据、推理与影响的工作仍会延续。

<a id="s5"></a>

## 承担未完成

我无法给出解释世界一切的一句话，也不能诚实宣称终极真理，但仍有写书理由。

仍有不愿承受的痛苦、未被理解的体验、缺少选择的人。有些条件可因理解改善，有些事可合作做到；知道答案不足时，也有修正之路。

合书后不必独担宇宙责任。也许只是使一个问题更精确，倾听某人，或休息以保护明天再思考的能力。

我愿一切存在都能不毁坏他人地过上珍视的生活，实现方式仍未完成。因此邀请读者共同更新问题，而非服从完成的思想。
