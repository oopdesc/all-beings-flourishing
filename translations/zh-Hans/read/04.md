# 第4章 目的发生冲突时

<a id="s2"></a>

## 所有愿望能同时实现吗

有人希望广场夜间也能享受音乐，住在附近的人则想安静睡眠。面对这两人，只说实现大家的目的，无法作出决定。

可以区分三件事：具体要求、要求背后的利益，以及保护利益的手段。深夜演出的要求背后，可能是音乐和交流的机会；安静的要求背后，可能是休息与健康。

调整时段、另设隔音场所、改变活动频率，扩展手段后，会出现原先二选一之外的方案。此时，与其消灭对方目的，不如理解目的、增加手段。

但并非所有冲突都能这样解决。同一时刻、地点、条件下，不能同时有声音又没有声音。承认冲突不是理想失败，而是准确指出要解决的地方。

<a id="s3"></a>

## 重新审视目的与否定一个人

目的未必从一开始就以完整形态存在心中。知识和经历改变，愿望也会改变。原以为不可缺少的东西，也许可以用别的形式满足。

因此，询问对方目的本身不等于否定自由。可以问怎样才不再困难、哪些部分不能改变、能否接受另一方案。被问者也需要不回答的自由和纠正误解的机会。

但若从外部规定“真正幸福就是这个”，把本人的话全部当成幼稚想法，审视目的便成为支配。尤其当掌握资源和地位者只要求弱势者忍耐时，更应警惕。

长期处于不利环境的人说“这样已经足够”，也不应忽略其话语，同时应确认是否真的存在选择。仅凭满意报告或外部标准，都无法充分理解其生活。

<a id="s4"></a>

## 如何对待伤害他人的目的

如果一方以使对方痛苦为目的，另一方不愿受苦，两项要求原样并不相容。只说平等实现双方目的，会为伤害辩护。

本书区分对存在的关怀与对要求的认可。应限制使人受苦的要求，但不必把提出要求者视为非人，也不必报复。在确保安全的同时，可以考察行为背景与其他相处方式。

这并非宇宙中所有存在已经同意的伦理，而是基于避免严重加害、保护自主的价值前提。不能保证不同价值观的人一定接受，因此除了对话，还需要法律、保护、限制权力和应对伤害。

追求合作，不等于失去离开危险的自由。不憎恨某人，与继续留在其身边也不同。共同目的不能成为困住受害者的理由。

<a id="s5"></a>

## 如实面对剩余损失

即使穷尽替代方案，时间资源不足仍可能使所有愿望无法满足。此时必须说明谁失去了什么，而不能假装没有损失。

先避免严重且难以恢复的伤害，再确保受影响者获得解释和申诉机会。价值仍无法比较时，应承认比较涉及政治与伦理判断。可行时考虑分担、补偿、轮换和限期试行。

这个顺序也不是自动解决所有情境的机器。自由可能相互冲突，保护可能需要限制。重要的是避免某个人只说“为了整体”就终结讨论，持续检验理由与影响。

“一切存在获得幸福”不是相信没有冲突，而是在冲突中也不预先把对方当成可以抛弃的对象。我希望把它作为寻找关怀尚未到达之处的问题，而不是宣布理想已经完成的旗帜。
