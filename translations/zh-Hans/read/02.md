# 第2章 连接事实与价值

<a id="s2"></a>

## 一句话里有不同的任务

“人离开他人合作就无法生活，所以应该珍视所有人。”这句话读来顺畅，但前半是在描述人的生活，后半是在提议如何行动。

仅凭相互依赖的事实，不一定能推出相互珍视的义务。有人也可能据此认为利用别人更有利。从前半走到后半，需要尊重对方生活、同时考虑利益与伤害等价值前提。

隐藏这些前提，会让人以为科学已经决定了唯一伦理。说明前提，读者就能指出赞同与疑问所在，更有利于继续讨论。

本书也不是让事实与价值脱离关系。即使选择减少痛苦，没有观察研究，也不知道哪种帮助有效。价值指引调查方向，事实修正手段与预期。两者可以在不混淆的前提下相连。

<a id="s3"></a>

## 用四个问题检验主张

首先问：这些词是什么意思？谈幸福时，若在快乐、满意、成就、安心、自由之间不断偷换，论证就无法接续。不必把它们定义成同一个东西，但必须说明在讨论哪一个。

其次问：相信它的理由是什么？是自己的经历、他人的报告、调查，还是数学证明？各有长处与限度。个人经历是理解当事人遭遇的重要材料，却不能证明全人类都有同样遭遇。

再问：有没有别的解释？使用某种学习方法者成绩较好，不一定全是方法的效果。也许本来更有动力的人选择了它，或者时间、教师、环境不同。

最后问：知道什么会改变想法？如果任何结果都能被说成理论正确，那么至少这些结果并未检验它。可以把它作为思想持有，但要称为实验支持，还需要别的条件。

这四个问题不只是驳倒他人的工具，也是让自己珍视的思想能够被他人检验的方法。

<a id="s4"></a>

## 推理正确也可能前提错误

“所有人愿望相同；愿望相同就不会冲突；所以愿望不会冲突。”即使形式整齐，首个前提也不符合现实。而且，即便愿望相同，若所有人都想要同一个座位，也会冲突。必须分别检验推理形式与前提内容。

证明是在确定前提与规则后，检验如何走到结论。证明辅助软件有时能严格核验推导，却不会自动保证现实幸福确实能由这些变量表示，也不会保证当事人接受前提。

本书的论证有同样限制。无法制造从任何地方都能提取真理的万能链条。可以做的是让人追踪哪里有经验证据，哪里有价值选择，哪里存在条件。

<a id="s5"></a>

## 逐渐成为科学的问题

部分哲学问题会随定义和测量方法的发展进入经验研究。心灵是什么这样的宏大问题，可以分出注意、记忆、知觉的具体课题。因此，当前无法观察不等于思考毫无意义。

但标上数字也不会自动成为科学。即使把“意识深度”自评为十个等级，不清楚测量对象时，也只是给谜团贴了数字。需要考察稳定性、与其他方法的关系，以及能否区分不同解释。

扩大科学范围，不是宣称未知已经已知，而是把原先只能用大词语讨论的问题分解，明确该观察什么。第15章至第20章给出具体例子。
