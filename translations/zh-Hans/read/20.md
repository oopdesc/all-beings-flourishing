# 第20章 数学保证与不保证什么

<a id="s2"></a>

## 先定意义再加符号

数学能明确前提关系，有时更易追踪改变后果及无法同时满足的条件。

把变量命名意识、幸福或宇宙目的，不使其自动可测。若不说明现实对应、取值、单位、预测与误差，计算仍只在符号中。

随机数据的漂亮曲线，不是真实意识幸福的证据。模拟考察假定后果，假定是否合现实须另验。

<a id="s3"></a>

## 矛盾与未解不同

未知答案与条件逻辑不相容不同。前者可能靠信息推进，后者需改条件定义。

同义、同时、同条件下要求成立与不成立，普通经典逻辑不能满足。说更聪明者必能同时满足，还须别的逻辑或解释。

有时只是词义或时间不同造成表面矛盾，可澄清解决。不要用万物皆矛盾抹去具体差别。

<a id="s4"></a>

## 不完备性定理说明什么

始于 Gödel、由 Rosser 加强的第一不完备性定理指出，对能表达充分算术、相容且可有效公理化的形式系统，存在内部既不能证明也不能反证的命题。[14][47] 条件很重要。

不能直接推出宇宙没有完整之物、无不存在或人必超机器。跨域使用须说明对象满足条件及结论含义。

承认知识有限重要，却不必扩张定理意义。精确条件下得强结论，是数学的重要启示。

<a id="s5"></a>

## 形式证明与对世界的正确

形式验证核实结论是否由定义公理导出，能减少遗漏。但生活表征是否合适、伦理前提是否正当，仍需形式化外的检验。

若程序被证明正确最大化幸福得分之和，测量不合适时，它只是正确最大化错误对象。须区分正确实现与正确目的。

本书是有限假设下的论证与可复现小计算，不是机器形式验证过的普遍伦理证明。应明确可形式化处，也使外部判断可见。

<a id="s6"></a>

## 如何尊重未知

承认不知似乎让人无话可说，但明确未知范围能缩小下一研究：定义、测量方法还是竞争解释比较？

我不愿失去问题规模，也不愿在大问题下堆未验证计算与权威名字。即便所知很小，确切说明，也能成为下一探究的足场。
