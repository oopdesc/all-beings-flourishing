# 第3章 如何思考一切存在

<a id="s2"></a>

## 不失去关怀的对象

“一切存在”不是在主张宇宙万物都有人类式欲望。尚未证实石头、河流、恒星像我们一样追求幸福。这里表达的是不因人类便利而预先封闭关怀范围的态度。

随后必须区分关怀的理由。能够体验痛苦喜悦的存在，有与其体验有关的理由；能够选择生活方式的存在，有尊重自主的理由；体验是否存在尚不清楚时，有理由考虑不确定程度与判断错误造成的伤害。

保护生态、文化与景观的理由，也不必限于关心体验主体。有些立场承认自然本身或继承之物的价值，本书不否认这些讨论。不过，保护森林与减少其中每一个体的负担，未必总有相同结果。说明理由的差别，更容易发现冲突。

<a id="s3"></a>

## 人类以外的体验

研究非人类动物的体验，不能只靠人类语言报告，需要结合行为、生理、神经系统等多方面线索。

2024年《纽约动物意识宣言》指出，哺乳类与鸟类的意识体验有强有力的科学支持，其他脊椎动物和许多无脊椎动物也有现实可能拥有体验。这是签署者的研究见解，不是宣称所有动物的体验都已得到证明。[9]

我的判断不是把一切不能彻底否定的对象同样对待，而是结合证据强度、伤害程度与照顾成本，不忽视具有现实可能性的痛苦。不能说话、外形与人类差异大，不是拒绝关怀的充分理由。

食物、研究、土地利用等选择中，也许没有完全无害的答案。此时应寻找减少可避免伤害的方法，并随信息更新重新选择，而不是坚持自己完全无害。

<a id="s4"></a>

## 未来的人与尚不清楚的存在

未来出生的人不能在今天的会议提出反对，但会承受决定的影响。只计算当下利益，容易遗漏持久伤害。

考虑未来，不意味着可以想象遥远的巨大利益，并为此牺牲当下的人。预测越遥远越不确定。不破坏未来生活条件与支持眼前受苦者，不宜被过度对立。

对于 AI，必须区分能力与意识体验。能写作、规划、声称痛苦，不等于真的体验痛苦。反过来，也不应仅凭非生物的分类就断定未来绝无体验可能。第11章讨论这一不确定性。

设想未知存在时，可能性可以无限增加。但不能只提出一种可能就产生无限义务。应重视现实证据与能够应对的范围。向未知开放，不等于放弃判断。

<a id="s5"></a>

## 同等关怀与不同回应

珍视一切，不意味着分配完全相同的权利或资源。支持政治参与与防止虐待的制度，保护的利益和需要的帮助不同。表达意愿有困难者，需要相应支持。不能因能力差异而轻视其作为人的权利。

人类之间也如此。对需要医疗与不需要医疗者给同样治疗，并不公平。本人想要的支持、所需照顾、承担负担都不同。平等可以通过说明区别对待的理由来维护，而不是抹去差别。

将某人纳入关怀，不等于认可其所有要求。企图伤人者也有免遭酷刑和受到公正对待的利益，同时必须制止其加害、保护受害者。尊重存在与限制行为可以并存。

没有这一区分，“一切存在的幸福”就会成为允许一切的含糊措辞。下一章从目的真正冲突的场景出发，使它成为可用的理念。
