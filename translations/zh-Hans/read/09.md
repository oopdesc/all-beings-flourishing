# 第9章 共同目的与自由并存

<a id="s2"></a>

## 不必选择相同人生

共同目的不要求同样工作、思想或幸福，而是共享不同目的者能够不相互毁坏地生活的条件。

有人投身音乐、家庭、研究，也有人想平静度日。不必统一为一种理想人生。应共同考虑选择机会、安全、对他人的伤害与资源分担。

《世界人权宣言》列出尊严、权利以及思想、良心和表达自由等。[7] 这不是宇宙终极真理的描述，而是如何对待人的重要公共标准。本书的共同目的也必须朝扩展自由的方向检验。

<a id="s3"></a>

## 有让所有人接受的决策方法吗

把多人的愿望合为一个社会决定很难。即便三人给三方案排序，多数决也可能循环。

甲偏好 A 胜 B 胜 C，乙偏好 B 胜 C 胜 A，丙偏好 C 胜 A 胜 B。两两投票时 A 胜 B、B 胜 C、C 胜 A，比较顺序可能改变结论。

Arrow 的社会选择研究，用数学说明同时满足某些理想汇总条件的困难。[6] 不能据此推出民主无意义或应交给独裁，而应说明选择了什么条件、牺牲了什么。

Sen 指出，扩大比较信息与条件，也会改变可作出的判断。[25] 不可能性结果不只用于关闭问题，也能成为寻找改变路径的起点。

因此，与其固定唯一方法，不如根据问题结合对话、投票、专业评价、权利限制和试行后复核。程序越复杂，越需要易懂说明。

<a id="s4"></a>

## 有知识者与受影响者

评估桥梁安全需要专业知识，但在哪里建桥、谁承担成本与噪音，不能仅由专家决定。应区分事实评价与利益负担分配。

本书不认为知识多者的票应机械地更重。定义何为知识的权力会成为新支配，现场生活与受害经验也可能不体现在考试分数中。

专家说明证据、预测与限度；当事人说明什么关乎生活、什么难以接受。二者区分虽不绝对，却不能相互替代。

即便意见不一，也应保护少数者记录理由、批评决定和事后纠正的权利。今天多数者不一定永远是多数。

<a id="s5"></a>

## 世界需要一个总指挥中心吗

关心全部存在，是否必须统一为一个管理机构？我认为没有必然性。集中一切，也会使错误和滥用从一处扩散。

当地能决定的留在当地，影响广泛的问题广泛协商。共享最低保护，也保留不同实践空间。多层机制能让人从差异中学习。

但分散不会自动公平，地方也可能有权力压迫和歧视。不能只凭不信任中央作答，而须在每一层检查问责、参与、救济与权力限制。

有共同目的的社会要健康，就必须允许批评目的的表述。不把服从作者或创始人作为良善标准，本书也不例外。
