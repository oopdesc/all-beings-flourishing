# 第6章 思考自我与他人的边界

<a id="s2"></a>

## 自己的体验为什么显得更近

自己的饥饿焦虑无需说明就知道，他人的则需从表情、语言和行为了解。这容易使自身利益显得切身，他人利益显得抽象。

但对我遥远，不等于对本人也遥远。其痛苦处于自身体验中心。即便我把别人当背景，对方的内在世界也不会因此成为背景。

重新审视自他边界的意义正在于此。认识到自己的视角不是整个世界，并非贬低自己，而是承认别人也有各自视角。

我不希望消灭一切差异，而是承认差异，同时不只因远近就极端改变价值。可以特别关心亲友，但不必从起点就把远方痛苦算作零。

<a id="s3"></a>

## 所有主观体验是否为一

我的思考中有一种设想：我们称为自己的体验主体，根本上是否是同一个主体，在不同生命中经历不同体验？

这不是当前科学已经确认的事实。

Kolak 讨论的开放个体主义也涉及类似问题。[34] 不能把我的设想当作前所未有的发现；有哲学先例也不能代替科学证明。脑或行为的共性，与体验主体在数值上同一不同。两台结构相似的机器不因此成为同一台，从共性走向同一性仍需额外论证。

而且，若所有主体为一与各主体分立的理论，对观察结果没有任何不同预测，当前观察便无法选择其中之一。它可以是有意义的哲学问题，却不能称为实验支持的理论。

作此区分后，设想仍可能有伦理作用：若从对方的位置体验世界，我希望怎样被对待？但这种视角有用，不证明其宇宙论意义上的正确。

<a id="s4"></a>

## 不同一也能关怀

要珍视他人，必须先证明他人其实是自己吗？我认为不必。

若主体彼此分开，他人拥有我无法替其体验的独特生命，这本身构成尊重理由。若根底有共同之物，现实中不同的身体、记忆、愿望和关系仍然存在，也不能因此粗暴对待。

接受第1章的公平与关怀后，两种假说都能支持倾听、确认同意和避免伤害。不宜让日常关怀完全依赖尚无答案的形而上学问题。

“你也是我，所以应该听从我的愿望”违背本书立场。若把他人当自身延伸来支配，质疑边界的思想反而抹去了他人。

<a id="s5"></a>

## 从无我学到什么

佛教有质疑固定独立自我，以及重视痛苦及其减轻的伦理传统。但教义不一，不能直接把无我替换成所有人都是同一意识。[19]

我希望学习的是不把自我固化为不变所有者的态度。身体、记忆、语言与关系使我成为现在的自己。维持自我与承认变化未必对立。

放松执着也不等于受害时不发声。若反思自我执着的思想被用于要求服从，这种用法也必须被质疑。

稍远地看自己，稍近地想他人，在往返中，即使没有主观体验的最终理论，也能改变相处方式。对边界谦逊，不是侵犯边界的许可。
