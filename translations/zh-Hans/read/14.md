# 第14章 将自我超越理解为更新能力

<a id="s2"></a>

## 超越什么

自我超越是不把昨天的理解当作今天的极限，能接触新信息、倾听他人、改变自身框架。

例如，了解生活条件后改变对某人不努力的评价；知道隐藏伤害后改变技术使用；承认反例后重写珍视理论。这些是具体更新，不是变成超自然存在。

超越对象不是他人的价值尊严。若成为超越弱者、跻身上位的竞争，就偏离扩展关怀。我不希望这词把别人置于下位。

<a id="s3"></a>

## 保护不成长的自由

珍视更新，不产生不停成长的义务。享受所学、稳定不变、休息恢复也需要时间。

“你还能更上一层”可能鼓励，也可能是不承认当前生活的压力，取决于本人状态及选择自由。

关心所有人幸福，不要求同速更新。一人前进时，另一人可以休息。接受支持者不是社会落后。更新制度应包含不必急于更新的空间。

<a id="s4"></a>

## 目的本身也需更新

只更新手段、永远认定目的正确，会高效实现错误目的。因此也要问为何增强能力。

本书共同目的不是神圣固定口号。范围足够吗？幸福遗漏了什么体验？是否以关怀剥夺自由？必须能根据现实反对意见修正。

但更新不等于不便时就丢弃承诺。应说明理由、受影响者和承担责任。承认错误的自由结合说明责任，才使更新可信。

<a id="s5"></a>

## 整个世界都在自我超越吗

生命进化、文化变化、科学进步，有时让世界显得在超越自身。这作为哲学想象有吸引力。

但观察局部变化，不推出宇宙有统一意志或一切必向幸福前进。变化也包括崩溃损失。科学的进化不等于伦理进步。

所以，本书不把宇宙反复自我超越当作观察已确立的解释。对人和社会，须具体定义更新、研究效果；对宇宙整体，须问什么观察能区分其他解释。

<a id="s6"></a>

## 没有完成形态不等于没有进步

不知最终形态，也可能判断改善：原来无法利用图书馆者获得入口，危险工作减少，错误信息被纠正。不必所有价值完全一致，也能赞同具体改变。

但改善也可能牺牲其他价值，如便利增加而隐私减少，收入增加而家庭时间减少。不要以进步一词掩盖，应说明得失。

自我超越不是必达完成的预言，而是即便自以为完成也不关闭复核通路的方针。我希望将其用于生活、写作与制度设计。
