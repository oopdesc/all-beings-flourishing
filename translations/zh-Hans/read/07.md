# 第7章 智能的限度与社会问题

<a id="s2"></a>

## 必须在不完全了解时决定

我们无法知道世界的一切再行动。选择工作或政策时，都不能完整预测未来。搜集信息的时间、比较能力与注意力都有限。

Simon 的有限理性主张在信息和计算限制内理解判断，而非把人当作能自由处理全部信息的理想计算者。[3] 本书所说智能限度不用于贬低特定人，而指包括我在内的判断者的限制。

复杂社会中，行动影响遥远地方和未来。只看自己可见利益，会遗漏他人伤害与延后成本。因此，深入理解与伦理有关：即使善意，也可能防不住看不见的伤害。

但知识增长不一定使人更善。准确预测既能帮助，也能用于精巧剥削。智能能帮助达成目的，却不会自动决定目的是否良善。

<a id="s3"></a>

## 不只用智能解释问题

只把社会问题解释为人类智力不足，会遮蔽利益失衡、权力集中、责任、资源短缺、歧视与历史。

例如，明知污染有害仍持续污染，未必因为不理解。制度可能让其获取收益、把成本转给别人。此时增加说明资料不会改变行为动机。

反之，选择匮乏者也可能采取长期不理想的行动。只责备智力人格，不会增加可选条件。应同时考虑判断支持与生活条件支持。

我也反对把善恶替换为智力高低。智力有多方面，不决定人的尊严。高智者可能加害，被评为低智者也可能关怀。以单一尺度排列人类、据此分配发言权，不等于尊重智能。

<a id="s4"></a>

## 让个人聪明与让群体聪明

即便专家优秀，不能表达异议的环境也可能使群体判断偏差。反之，个人知识有限，但能汇集信息、纠错、分担责任，也可能形成个人找不到的方案。

重要的不只是人数，还有谁的信息能到达、谁的被忽略。了解现场者不能参会，报告失败会受罚，只上报负责人喜欢的数字，都会让既有信息无法用于判断。

因此，提高社会智能包括教育、清晰说明、记录、验证、申诉和报告内部问题的渠道。增加知识与打通知识通路，是分别必要的工作。

<a id="s5"></a>

## 发现自身错误的能力

我特别重视发现并修正错误的能力：不只会用难词解释，更能检查解释在哪里失效；不只自信，更能说明改变信心的条件。

提出方案时，考虑它为何可能失败；询问受影响者的担忧；试行前定义成功和中止条件。这不是天才独有的能力，而是可以分享的程序。

AI 能辅助，但只增加貌似合理的解释，也会强化错误。扩展智能必须同时扩展核验机制，而非只增加答案。

人类智能有限，不代表人类价值低。正因为有限，才需要分享知识与权力，建立相互修正的关系。下一章讨论其成立条件。
