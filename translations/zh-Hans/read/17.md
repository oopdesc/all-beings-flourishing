# 第17章 将理想转为可检验问题

<a id="s2"></a>

## 缩小要核实的内容

共同目的改善世界的主张太大，不能直接确定调查方式。应区分哪个群体、共享什么、与什么比较、预期什么改变。

例如可以问：共同作业前讨论目的、负担与异议渠道，是否比不讨论更能改善理解和负担公平感？这不是证明宇宙最终目的，而是在有限条件下检验具体程序效果。

已有相关研究时，应先读再想新实验，确认哪里已知、什么尚未复现。词语类似但测量不同，不算同一研究。

<a id="s3"></a>

## 区分好感、行为与制度

对对立群体更有好感，民主行为就会改善吗？可能相关，但一项改变未必全部改变。

2024年大规模研究比较25种减少美国党派敌意或反民主态度的干预。[30] 2025年研究则考察减少敌意的效果大小、持久性及向其他民主态度扩散的限度。[31]

不能据此说对话无意义，也不能说增加好感就解决政治。须区分对象、干预、测量时间与结果指标，也不直接推广到所有国家、职场或宗教冲突。

共同目的也一样。赞同措辞、信任对方、实际合作、伤害减少、长期持续，应分别测量。不把最初一项改善称为最终理想实现。

<a id="s4"></a>

## 提前决定什么

研究应在看结果前明确问题、比较、主要指标与分析方法，避免事后只将有利结果称成功。

例如把正确解释共同作业内容的比例定为主要结果，满意度与持续意愿另列。还须规定对象、人数、分配、测量时间和退出者处理。

样本量须根据最小有意义变化、变异、群内相似性和脱落预期，而非凭感觉。小试行没发现变化，不一定证明无效果。

多指标测试更容易偶然出现好看结果，应报告效果大小、不确定性、不利结果与负面影响。事后提出假说须标作探索性。

<a id="s5"></a>

## 保持比较公平

试行与未试行群体起初差别很大，就不能把结果差别断定为程序效果。须根据条件用随机分配等设计减少其他原因。

随机化也非万能。组间信息传播、知道受观察而改行为、仅愿答者留下等，都需因地制宜并记录限制。

职场学校中，对上司教师的顾虑会扭曲同意。必须实际确保拒绝无不利、个人回答不用于评价、信息受保护。不应省略必要伦理审查和专业讨论就开始思想实验。

<a id="s6"></a>

## 哲学哪部分进入科学

如此分解后，并非整套共同目的哲学成为科学，而是其中程序与影响的部分能够检验。

应珍视谁的价值判断本身不是实验结果；程序在某条件下怎样改变理解和负担，则可获支持或反证。两者都重要，但回答方式不同。

本书研究计划是未实施提案，不报告已做实验或使人幸福。先读已有研究、识别未知、必要时检验，理想才接受审视。
