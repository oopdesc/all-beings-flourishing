# 第12章 生活意义与目的的更新

<a id="s2"></a>

## 意义从何而来

不证明宇宙有最终目的，生活就无意义吗？我不这样认为。与人相处、理解未知、支持困难者，即便没有宇宙整体解释，也可能对当事人有意义。

意义不只指宇宙外给予的命令，也包括事物重要、行动可理解、参与关系活动。但词义无限扩张便什么都能解释，因此须确认每次问的是哪种意义。

宇宙为何存在，与明天珍视什么而生活，可能相关却不是同一问题。前者无答案，仍可思考、选择并讨论后者。

<a id="s3"></a>

## 没有目的的时期也是生活的一部分

提议共同目的的书，不应要求每个人承担宏大使命。疾病、疲惫、失落中，可能无法考虑未来。先吃饭、休息、处于安全之地就可以。

目的不清的人，生命价值并不更低。目的不是资格考试。帮助其能够选择，以及保留暂不选择的余地，都属于关心所有人幸福的立场。

有用也非唯一意义。享受事物、看美景、与亲近者聊天，不必提交成果报告。以社会贡献换取存在资格，会逼迫需要支持者。

我的共同目的不是建立此种资格，而是从能力业绩不同也有保护生活的理由出发。

<a id="s4"></a>

## 改变目的的自由

选择过的目的不必永远服从。知识、关系、状态变化后，旧目的可能不再适合。

改变目的不等于努力全白费。学习和关系可能连接其他活动；也不必强行把损失说成没有。承认失去时间机会后，仍可考虑未来选择。

更新时说清改变了什么：手段不合，还是目的不合？兴趣变了，还是生活条件更严峻？区分后便不必在全部放弃与全部继续之间二选一。

承认自己的改变自由，也应承认他人的。昨天同意不能永远算作今天同意。合作需要复核与退出空间。

<a id="s5"></a>

## 不把意义锁进一个方程

可以调查有意义的活动及相关因素，但不等于能用普遍方程说明全部意义。

语言不仅有信息性质，还与说话者、对象、情境、目的相关。同一句“没关系”可能鼓励，也可能驳回诉说。仅看字符串，无法确定作用。

Shannon 通信理论为处理工程问题，将语义问题分离形式化。[15] 理论强大，不意味着信息量大小就等于人生意义或伦理价值大小。

我不想把意义排除出理性探究，而想选择适合问题的方法：倾听体验、解释语言、观察行为、展开调查。明确各自能知范围，才能推进理解。

<a id="s6"></a>

## 共同目的提供什么

思考一切存在的幸福，是我选择学什么、做什么、拒绝什么的方向，却不提前给出所有答案。

用它停下追问：改善谁的生活？谁承担负担？自己还能继续吗？是否为了目的采用违背目的的手段？

如此，意义不只在遥远完成点，也在学习、修正、与他人联系的过程。尚不知终极真理，不使过程空白。
