# 第22章 在日常与共同活动中尝试

<a id="s2"></a>

## 连接明天的行动

大目的不直接决定今日行动，面前仍有工作、家务、疲惫与家人。忽略生活、把理想放远，无法持续。

先具体指出一个困难：解释太难、无人咨询、工作集中一人。不让其代表全部世界问题，而说明谁为何困扰。

再确认本人希望及已尝试之事。有时不宜立刻执行自想的帮助，提问也要避免让受助者承担过多解释负担。

从可撤回修正的小范围开始，之后检查变与不变。没结果时，先查方法条件，不先责备努力不足。

<a id="s3"></a>

## 设计虚构学习会

假设共同学习会目标是让参与者能自行解释、应用、必要时重新调查，而非仅增加人数或资料数量。

参与者有时间受限者、初学者、想深入者、表达有负担者。同样作业不一定公平。

可备共同短说明与可选练习，允许现场或事后书面提问，保证说不懂不降低评价，尽量让本人选择是否接受建议。

公开分工：资料、主持、答疑、场地各由谁做多少。集中善意一人就减少活动或调整分担，不为持续而隐藏疲惫。

<a id="s4"></a>

## 怎样看成功

问是否开心有意义，但不能判断能否独立应用；只看解题，也难看见焦虑疏离。

分别检查能否自述、应用新小任务、困难时提问。不必公开回答，也可不以比较排名为目的。

还要问准备时间、参与费用、没懂者感受及中途退出原因，不能只看留下者就认定人人有益。

这是设计例，不是实证有效方案。实际应用须适配、同意并保护信息；研究效果主张须补充第17章那样的设计。

<a id="s5"></a>

## 不止于个人实践

个人关怀重要，但疾病支持、教育机会、劳动条件、住房、安全、反歧视都与制度相关，不能全归心态。

共同目的只指方向，不自动保证政策正确。应查效果、成本、分配、可行性与替代方案，一地成功不保证他处同效。

也需保护未来生活条件。IPCC 2023年综合报告整理人为变暖、影响和应对。[20] 环境既不只个人节约，也不是个人毫无作用，而是制度、技术、生活的关系。

不耗尽善意，创造良好行动容易持续的条件，比只想把每个人改造成更道德者更能分担负担。

<a id="s6"></a>

## 不把关怀关在个人性格里

Ozawa-de Silva 与 Mascaro 2026年论述提出从人际行为、群体环境、社会制度多层研究同情关怀，而非只看内心。[46] 它不是完成测量法或保证有效制度，文化适配定义与指标验证仍待研究。

日常也如此：接待者倾听、职场确保时间人员、制度降低费用手续障碍，任何一项不能代替其他。

我不提议给个人善意打分，而要同时看求助者是否真的抵达帮助、帮助者是否被过度要求。区分意图、行动、受助体验、制度结果，才能找到仅呼吁更关怀看不见的改善处。

<a id="s7"></a>

## 简短写下自己的方向

试写当前立场：想保护什么、已知未知什么、核实什么会改变行动？

无需长宣言。例如想减少听不懂说明者，尚不知卡在哪里，所以听愿意说者。这已连接目的、未知与行动。

过段时间重看，不只问达成否，还问表述合适否。无需变则继续，有理由则修。没有进展的一天也不是价值判决。

使用本书不是重复作者结论，而是让行动理由能与他人共同核实。
