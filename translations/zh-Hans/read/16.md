# 第16章 公平判断不能只靠数字

<a id="s2"></a>

## 总和大就足够吗

三人面对三方案。A 的评价为10、10、负2；B 为5、5、5；C 为4、7、6。数字仍属虚构，假定真实幸福可用共同尺度测量，仅为解释。

总和分别18、15、17，只看总和会选 A。但若第三人的负2包含严重侵权，不能只凭总和接受。

可先排除违反最低保障的方案。若本例最低条件定为所有评价至少零，便排除 A，留下 B、C。

零不是从自然发现的伦理，而是例子设定。现实标准须考虑法律、权利、当事人意见及伤害性质，不能用数字外观隐藏判断。

<a id="s3"></a>

## 看最不利者还是总和

剩余方案中，总和最大选 C，最低评价尽量高则选 B。选择并非只由计算正误决定。

从 B 改 C，第一人由5降4，第二由5升7，第三由5升6。不是无人变差而有人变好，而是有改善也有负担。

Parfit 区分把差距本身视为问题与更重视不利者受益的立场。[32] 不能仅用为了大家抹去差别。

只看最低状态，可能漏掉其他巨大改善；只看总和，可能忽视少数严重负担。本书不提供万能伦理公式，而说明使用何种标准、忽略什么。

<a id="s4"></a>

## 可以与不能比较的部分

所有人至少不变差、至少一人变好，通常称帕累托改进。若可能，就有很强理由考虑。

但须核实何谓改善，是否计算外部人影响与未来负担。眼前三人改善，却转嫁伤害给别人，不能称整体改善。

没有剩余帕累托改进，也不保证分配公平。极端偏斜的状态也可能无法在不使某人变差下改善。效率与公平是不同性质。

先确认可比较处，未决部分由当事人参与价值判断。指出哪里未定，比隐藏更利于下一步讨论。

<a id="s5"></a>

## 预测也有不确定性

现实中评价本身也未知。生活改善预测有误差和遗漏，不可只挑有利点估计就宣称最优。

若预测甲改善1至3，乙影响为负1至2，就不能保证人人变好。乙可能受损，减少不确定性的调查或小试行也许有价值。

不确定不只在预测，也在何者为善。道德不确定性研究提出同时考虑多个伦理理论。[28] 也有研究批评用共同尺度处理不同理论。[29] 本书不认为一个公式已解决争论。

<a id="s6"></a>

## 决定与能够纠正

不能因不确定就永不决定，不行动也有结果。因此依当前证据选择，并同时准备发现错误后的应对。

谁确认影响？何种伤害须中止？困难者向哪里申诉？承诺未兑现谁解释？这些是判断本身，不是计算后的附加物。

思考一切存在的幸福，不是成为掌握全部信息的唯一计算者，而是让被自身计算遗漏的人能够重新进入。
