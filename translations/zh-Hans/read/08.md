# 第8章 创造合作的条件

<a id="s2"></a>

## 合作不能只靠善意维持

多人分担个人解决不了的问题：研究疾病、维护道路、积累知识、应对灾害。我们的生活有许多工作以合作为前提。

但合作有利整体，与每个人都有合作理由不同。不付成本也能享受成果时，不出力可能更有利。若出力者疲惫、不出力者同样获益，负担便集中于善意。

Nowak 对合作进化的整理，讨论亲缘、互惠、互动结构等多个机制，把合作视为有成立条件的现象，而非无条件产生的性质。[4]

Andre 等2026年6月的研究在125国、101,123人的有偿双人实验中报告69%选择合作，而且人们倾向低估他人的合作。[37] 两人都减少一部分私人所得时，就向气候行动捐款。观察到的是特定收益、受捐对象和说明之下的选择，不证明现实冲突或长期事业能按相同比例解决，也不证明所有人共享一套价值。

这类研究不会直接决定唯一社会制度，生物进化发生的事也未必伦理上可取。不过，比起只呼吁合作，研究其支持条件仍很重要。

<a id="s3"></a>

## 共同目的之后仍有问题

即便组织有同一目标，解释、分担、成果和紧迫程度不同，仍会冲突。赞同目标也不等于有同样任务和时间。

十人想办学习会，若只有一人订场地、备资料、清扫，最终仍难持续。共同口号不能代替公平负担。

应使工作可见、确认参与能力、轮换角色，必要时缩小活动。只说目标重要请忍耐，就会使共同活动依赖个人牺牲。

不参与的理由也不同。只想获益者，与生活没有余力者、未获信息者、因过去受损而警惕者，不能同等处理。不问理由，制度可能先排除弱者。

<a id="s4"></a>

## 不把一种制度当万能药

Ostrom 批评用同一制度解决所有环境与资源管理问题，提出依情境诊断制度和条件的框架。[5] 共享或私有、国家或市场的单一分类，不足以处理实际差异。

本书不接受消灭资本主义就解决一切，或交给市场一定改善的答案。价格协调、公共服务、共同管理各有适用情境，应调查谁的何种利益受保护、谁承担何种负担。

竞争也不都等于冲突。规则公平、参与自由、失败者生活不被毁坏时，竞争可能培养技能与创意。涉及地位生存的竞争也可能造成隐瞒与耗竭。应检查条件与影响，而非只问有无竞争。

并非所有经济活动都要求一人增加财富、另一人等量变穷，也可能创造新价值。但价值归谁、成本转给谁，仍需另问。

<a id="s5"></a>

## 设计合作时要确认什么

先明确一起做什么、哪些留给个人。使信息和工作可见，说明负担与收益，规定决策方式和求助渠道。

再设定检查结果的时间。参与者满意也可能伴随外部伤害，应查看未参与者和难以发声者的影响。失败就调查理由，保留缩小或停止的选择。

这种设计不只出于不信任人。善意者也有极限，只依赖善意的组织会在其疲惫时崩溃。持续合作需要保护合作的人。

共同目的指引机制，机制将目的化为日常行动，缺一不可。后面的数学模型将再检验这种关系。
