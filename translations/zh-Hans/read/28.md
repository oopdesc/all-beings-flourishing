# 附录D 阅读既有研究的指南

调查基准日为2026年10月26日，是相关性优先的选择性调查，不是穷尽世界文献的系统综述或新元分析。主张强度不只由年份刊物决定。

<a id="s2"></a>

## 幸福与良好生活

先看第5章区分，再读 OECD、Global Flourishing Study 初报与2026年多维比较。[1][24][38] 分开概念选择与回答、生活条件数据，并读规范前提批评。[45]

国家群体平均不代表每个人；相关不定因果。翻译、抽样、时间、缺失脱落均影响含义。

<a id="s3"></a>

## 合作与制度

读2026年实验时核对选择、报酬、伙伴信息。[37] 转到现实事业须查时长、责任、资源、关系差别。

Ostrom 诊断制度与社会困境研究可结合，以区分心态与利益结构。[5][43] 不把制度当万能药。

<a id="s4"></a>

## 社会选择与正当化

分开读 Arrow 的条件结论，[6] 再读 Sen，观察改变比较信息后的可能。[25]

公平有平等与优先之分，也有重视向个人说明理由的论证。[32][33] 本书不称完全统一，须比较评价单位与异议处理。

<a id="s5"></a>

## 道德不确定性

Moral Uncertainty 讨论如何把对正当性的未知纳入决定。[28] 也有将不同理论评价合为期望值的批评。[29]

读提案后读反对，再看何者仍可行，不把任一题名当最终结论。

<a id="s6"></a>

## AI、人类学习与价值汇总

区分辅助中成果与撤除后理解。[49][50][51] 不同教材、对象、测验时距，不算同效简单复现。

从综述进原著时核对效用定义与比较数据来源。[52] 前后分析条件不同时，不只比结论强弱。[53][54] 始终分数学保证与价值选择。

<a id="s7"></a>

## AI 意识

将2026年指标论文、内部功能预印本、校准迁移论述、数字意识怀疑评论分类型阅读。[36][41][39][40]

核对系统、理论前提、观察功能、功能到体验的推论，并警惕标题强于证据。

<a id="s8"></a>

## 关怀研究的阶段

2026年多层框架应作为新视角与测量提案阅读。[46] 有指标名字不等于效度效果已证实，应分构想、开发、验证、实践效果。

<a id="s9"></a>

## 宇宙研究

看观测、假设模型、约束参数，DESI 2026年研究也是如此。[42]

模型未知不等于确认宇宙意志或目的，不以未知支撑另一大断言，而由未知提出新问题。

<a id="s10"></a>

## 自建读书记录

每篇短记问题、方法、结果、局限、与本书关系，记录看过全文、摘要、出版介绍还是仅标题。

引用须核对原资料相应处，不把二手介绍当亲读原著。有反驳也不直接认定原研究无价值，应识别争点。

这些记录让未来读者和 AI 知道重查何处，而非盲目继承。
