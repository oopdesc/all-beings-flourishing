# 第19章 理解宇宙与追问目的

<a id="s2"></a>

## 可观测宇宙与全部存在

理解宇宙是我思考的核心。为什么有事物、时间是什么、存在有终结吗？问题宏大，但不必急于统一答案。

现代宇宙学用观测与模型研究膨胀、早期高温高密状态及后续变化。[12] 可追溯历史与存在本身为何存在，范围不同。

大爆炸模型不证明一切由哲学意义的绝对无产生。对可观测范围外或最早状态，也不能任意断言。

解释局限不是向空白填入偏好答案的许可，应区分观测、模型与未解条件。

<a id="s3"></a>

## 2026年研究展示的进路

2026年 DESI 研究利用遥远氢吸收光的相关性等，约束膨胀史与模型参数。不同数据组合和暗能量假设，会改变支持程度。[42]

研究对象是可观测量与可比较模型，不是用同样数据测量宇宙是否追求幸福或全部主观为一。

值得学习的不只是强结论，而是精度、替代解释、系统误差及可随新观测改变的态度。真理热情由细致工作支撑。

所参 DESI 版本为预印本。团队规模与精密测量不会消除发表状态和解释不确定性。

<a id="s4"></a>

## 秩序违背热力学吗

生命文明复杂化似与熵增冲突，但局部秩序与包含环境的总熵增加可以并存。

第二定律需重视系统边界，不直接禁止开放系统局部形成秩序。[13] 学习建造不必解释为反抗物理。

物理秩序与伦理良好社会也不同。严格管理可能损害自由幸福，不能由物理词直接推导政治理想。

<a id="s5"></a>

## 无限过去与现在

无限过去要经过无限时间才到现在、所以现在不该到来的说法直观，却不是过去有限的数学证明。

整数向负方无尽延伸，仍有零。没有第一个整数不等于没有某个位置。这不说现实时间就是整数列，只说明无起点不直接推出无现在。

讨论真实时间起源结构，须结合物理、观测与时间含义。直觉能提问，不能独自确定宇宙史。

<a id="s6"></a>

## 改变物理法则的愿望

希望不可能成为可能能推动研究，但造装置、修订自然理论与改变自然法则本身不同。

飞机不是因重力消失而飞，而是建立了在条件中工作的机制。过去技术突破不保证连逻辑矛盾愿望都可实现。

我不想把理想限于当前技术，也不想把强烈理想当作可行证据。区分障碍，才能分清可用巧思改变与仍未知的条件。

<a id="s7"></a>

## 即使不知道宇宙目的

觉得宇宙有生命、想象整体认识自我，可以作为哲学表达，却不是观测确立的目的。

即便宇宙有目的，是否对我们可欲仍是另一问题。自然发生的不自动是应服从的善，须区分发生之事与想保护之物。

理解宇宙有助认识可能与限度。但在完整答案之前，已有理由回应痛苦、保护自由、支持研究。我希望大谜团与今日关怀同在人生中。
