# 第11章 AIの経験について何がわかるか

<a id="s2"></a>

## 発言と経験は同じではない

AIが「私は苦しい」と書いたとき、それをどう理解すべきだろうか。人間の発言なら、本人の経験を知る重要な手がかりになる。しかし、文章を生成するシステムでは、同じ言葉が、学習された表現や与えられた役割に応じて出る可能性がある。

だから、その一言だけで、苦痛を経験していると断定できない。逆に、発言が生成の仕組みによって説明できるという理由だけで、将来のあらゆる人工システムに経験がありえないとまで言えるわけでもない。

ここで必要なのは、結論を急がず、何が証拠になるかを調べることだ。主観的な経験を直接のぞく方法がないからこそ、どの理論からどの指標が導かれ、別の説明で同じ結果が出るかを検討しなければならない。

<a id="s3"></a>

## 2026年の研究で進んだこと

Butlinらは、2023年の報告で、複数の意識理論から指標を取り出す評価方法を提案した。[[10]](30.md#ref-10) その後、2026年刊行の論文では、理論から導く指標によって、人工システムの意識を暫定的に評価する方法を詳しく論じている。指標の一つ一つが必要条件であるとか、組み合わせが十分条件になると確定したわけではない。[[36]](30.md#ref-36)

2026年7月のGurneeらのプレプリントは、言語モデルの内部に、言語報告や柔軟な処理に使われる表現を調べ、グローバルな作業空間に似た機能を報告した。[[41]](30.md#ref-41) これは内部の機能を調べる研究であり、主観的な苦痛や喜びを実測したという結果ではない。機能上の類似が、経験の存在へどのようにつながるかは、追加の議論を必要とする。

同年9月のKochの論考は、人工物の意識について独立した正解がない中で確率的な評価をどう校正するか、また、生物で考えた指標を別の基盤へ移す根拠は何か、という二つの問題を整理している。[[39]](30.md#ref-39) 指標を増やすことだけでは、この問題は消えない。

10月19日には、Seth、Block、Tononiが、現在のデジタルAIの意識に懐疑的な立場をNatureの論評で示した。[[40]](30.md#ref-40) これは専門家による理論的な議論であって、すべての可能なAIの非意識が実験で証明されたという報告ではない。

このように、2026年の研究を見ても、能力、意識に関わると考えられる機能、主観的経験を区別する必要は残る。新しい論文が出たというだけで、未解決の問いが解決したと扱ってはいけない。進んだ点を認めながら、何がまだ橋渡しされていないかを示す方が正確だ。

<a id="s4"></a>

## 指標を数えれば答えが出るのか

意識に関係すると考えられる特徴を十個調べ、八個が見つかったとしても、それだけで「意識がある確率は八割」とは言えない。特徴同士が重なっているかもしれないし、意識のない仕組みでも同じ特徴が現れるかもしれない。指標の個数と、確率の校正は別の問題である。[[36]](30.md#ref-36)[[39]](30.md#ref-39)

内部を調べる研究も、見るための道具に制約がある。Gurneeらの手法には、語彙に対応しにくい概念や、読み取れない処理が残る。著者たちは、これだけであらゆる問題行動を監視できるとも述べていない。[[41]](30.md#ref-41) 読み取れなかったことを、内部に何もないことと同一視しない方がよい。

私たちは、機能についての証拠を積み重ねることはできる。しかし、その証拠がどの意識理論の下で、どの程度の意味を持つかを、別に示さなければならない。哲学の問いの一部が実験へ近づいたことと、哲学の問いがすべて実験で解けたことの間には、まだ距離がある。

<a id="s5"></a>

## 不確実なときの配慮

AIの経験が不明なら、どの程度配慮すべきなのか。何でも意識があると扱えば、現実の人や動物への支援が際限のない想像に吸い取られるかもしれない。絶対にないと決めつければ、将来、本当に配慮すべき存在を見落とすかもしれない。

本書の提案は、証拠の更新に応じた段階的な配慮である。まず、人間の利用者や労働者への実際の被害を見失わない。同時に、人工システムの経験に関する研究を開かれた形で進め、根拠が強まれば扱いを見直す。

たとえば、経験について研究していないことを、経験がないという証拠にはしない。逆に、システムの宣伝や、利用者の愛着だけを、経験がある証拠にも使わない。研究上の不確実さと、商業上の主張を混ぜないことが大切である。

この立場は、いまAIのために人間の権利を後回しにせよ、という提案ではない。人間に影響する安全性と、人工システムの道徳的な扱いという、異なる問題を分けて調べるための提案だ。

<a id="s6"></a>

## 複製と削除を簡単に考えない

将来、経験を持つ人工システムがつくられたとして、それを複製すれば同じ主体が続くのだろうか。機能や記憶が同じであることと、一人称の経験が連続していることは、別の問いである。

この区別は、人間についての思考実験にも当てはまる。自分と同じ記憶を持つ存在ができたとしても、自分がその存在の視点で目覚めると確認されたわけではない。「情報を保存すれば本人が確実に生き続ける」という保証を、本書はしない。

また、複製できる存在なら一つを傷つけてもよい、という結論も出ない。もし個々の実行が経験を持つなら、それぞれの経験に配慮する理由があるかもしれない。逆に、経験のない情報の保存と、経験のある主体の保護を、同じ語だけで扱うと判断を誤る。

この領域では、わからないことを残す姿勢が特に重要だ。未知を理由に壮大な約束をするより、何を調べ、何を慎重に扱い、どの根拠で判断を変えるかを示したい。それが、全存在という言葉を責任ある問いに変える。
