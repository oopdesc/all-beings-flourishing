# 第12章 生きる意味と目的の更新

<a id="s2"></a>

## 意味はどこから来るのか

宇宙に最終目的があると証明されなければ、私たちの生活には意味がないのだろうか。私は、そうは考えない。誰かと過ごす時間、わからなかったことがわかる経験、困っている人を支える行為には、宇宙全体の説明を持たなくても、当事者にとっての意味がありうる。

ここで言う意味は、宇宙の外から与えられる命令だけを指さない。何かが大切であること、自分の行動が理解できること、関係や活動に参加していることも含む。ただし、意味という言葉を広げすぎれば何でも説明できてしまう。どの意味を問うているのかを、その都度確かめる必要がある。

「なぜ宇宙が存在するのか」と、「明日、自分が何を大切にして生きるか」は関係しうるが、同じ問いではない。前者の答えがまだなくても、後者について考え、選び、他者と話すことはできる。

<a id="s3"></a>

## 目的を持たない時期も生の一部である

共通目的を提案する本が、すべての人へ大きな使命を要求してはいけない。病気や疲労、喪失の中にいるとき、将来の目的を考えられないこともある。いま食べ、休み、安全な場所で過ごすことが先でよい。

目的が明確でない人の生が、明確な人の生より価値が低いわけではない。目的は人の価値を認めるための試験ではない。選べるようになるための支援も、まだ選ばずにいられる余地も、全員の幸福を考える立場には含まれる。

また、他者の役に立つことだけが、生の意味ではない。何かを楽しむこと、美しいものを見ること、親しい人と話すことに、成果の報告を求める必要はない。社会への貢献によって存在する資格を得るという考えは、支えを必要とする人を追い詰める。

私の共通目的は、そのような資格をつくるためのものではない。能力や実績が違っても、生活を守られる理由があるという立場から出発する。

<a id="s4"></a>

## 目的を変える自由

一度選んだ目的に、永遠に従わなければならないわけではない。知識が増え、関係が変わり、自分の状態が変われば、以前の目的が合わなくなることがある。

目的を変えたことと、努力がすべて無駄になったことは同じではない。その過程で学んだことや築いた関係が、別の活動へつながる場合もある。ただし、損失がなかったと無理に言い換える必要もない。失った時間や機会を認めたうえで、これからの選択を考えられる。

目的を更新するときは、何が変わったのかを言葉にしてみる。実現手段が合わないのか、目的そのものが合わないのか。自分の関心が変わったのか、生活の条件が厳しくなったのか。違いを分ければ、全部を捨てるか、全部を続けるかの二択から離れられる。

自分の目的を変える自由を認めるなら、他者にもその自由を認める必要がある。昨日の同意を、いつまでも今日の同意として扱わない。協力関係にも、見直しと退出の余地が必要だ。

<a id="s5"></a>

## 意味を数式一つへ閉じ込めない

意味のある活動について調査し、何がその感覚と関連するかを研究することはできる。しかし、そのことと、すべての意味を一つの普遍的な方程式で説明できることは違う。

言葉には、情報としての性質だけでなく、話し手、相手、場面、目的との関係がある。同じ「大丈夫」という言葉も、励ましになるときと、訴えを退ける言葉になるときがある。文字列だけを見ても、その働きは決まらない。

Shannonの通信理論は、通信の工学的な問題を扱うために、意味の問題を切り離して定式化した。[[15]](30.md#ref-15) その強力な理論があるからといって、情報量の大小が、そのまま人生の意味や倫理的な価値の大小になるわけではない。

私は、意味を知的な探究の外へ追い出したいのではない。むしろ、問いに合う方法を選びたい。経験を聴くこと、言葉を解釈すること、行動を観察すること、調査すること。それぞれでわかる範囲を明らかにすれば、意味についての理解も進められる。

<a id="s6"></a>

## 共通目的が与えるもの

「すべての存在の幸福を考える」という方向は、私にとって、何を学び、何をつくり、何を断るかを考える軸になる。しかし、その軸が、すべての場面の答えを先に与えるわけではない。

軸は、立ち止まって問い直すために使う。これは誰の生活をよくするのか。誰が負担を負うのか。自分はいま続けられる状態なのか。目的のために、目的に反する手段を選んでいないか。

このような問いを持つなら、意味は、遠い完成点だけに置かれなくなる。学びながら、修正しながら、他者と関わる過程にも置ける。最終真理をまだ知らないことは、その過程を空白にする理由にはならない。
