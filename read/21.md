# 第21章 知識を共有しながら人を守る

<a id="s2"></a>

## 公開することに何を期待するか

私は、この本を、誰かが考え、直し、次のものをつくるための足場にしたい。完成した教義として保管するより、使われ、批判され、必要なら書き換えられる方がよいと考える。

公開には、一人では気づかなかった誤りを指摘してもらえること、同じ作業を繰り返さずに済むこと、異なる知識が結びつくことへの期待がある。しかし、公開しただけで、必ずよい結果になるとは限らない。誤情報も広がるし、理解するための時間や教育がなければ、情報が届いても使えない。

したがって、共有には説明が必要だ。何を主張し、どこに根拠があり、何が未確認で、どう直せばよいかを示す。専門家だけに読める形と、初めて学ぶ人が追える形を結びつけることも、共有の仕事に含まれる。

<a id="s3"></a>

## すべてを公開すればよいわけではない

知識を開くことと、個人情報を無制限に広めることは違う。住所、健康、家族、職場、他者との会話などには、公開によって生活を損なう情報が含まれうる。本人が考えを共有したいことは、周囲の人の情報まで公開する同意ではない。

危険な利用に直結する情報や、第三者の権利を侵す内容についても、公開する理由と被害を比較する必要がある。知識の共有という目的を、すべての公開を正当化する一語にしない。

UNESCOのオープンサイエンス勧告も、開放性とともに、倫理やプライバシーなどの条件を扱っている。[[21]](30.md#ref-21) 本書が目指すのも、人を守る条件を含む共有である。秘密を持つこと自体を、協力への裏切りとみなしてはいけない。

<a id="s4"></a>

## 出典は飾りではない

出典をつける理由は、文章を権威づけるためだけではない。読者が、どの主張を、どの資料に基づいて書いたのかを確かめ、必要なら元の議論へ戻れるようにするためである。

実在する文献でも、本文の主張を支えているとは限らない。対象の違う実験、理論上の提案、専門家の意見を、すべて実証結果として並べない。また、一つの研究が提案したことと、その後に広く支持されたことも分ける。

本書では、引用符による長い転載を避け、論旨を自分たちの言葉で説明し、対応する出典番号を付した。論文や著書の存在を確認するだけで、その全体を精読したと述べない。確認した範囲を超える結論を、著者の名前へ預けない。

新しい文献が古い文献より常によいわけでもない。新しい研究は、以前の問いをどこまで進め、どこを修正したかを読む。基礎となる定理や古典的な議論を、刊行年だけを理由に捨てない。

<a id="s5"></a>

## 貢献を消さずに受け渡す

知識を広く使えることと、誰が何を積み重ねたかを残すことは両立する。出典を消して新しさを装えば、元の主張と後から加えられた主張を区別できず、誤りを直す場所も見えにくくなる。原点への表示は、著者への敬意であると同時に、読者が検証するための手がかりになる。

研究成果の記録には、構想、調査、執筆、編集などの役割を分けるCRediTという標準がある。[[55]](30.md#ref-55) これは著者の肩書を認定する制度でも、結論の正しさを保証する制度でもない。本書でも、oopdescによる構想と原資料、AIを使った調査支援・生成・編集、今後の寄稿者の訂正を区別して残す。AIを人間の寄稿者と同じ責任主体として扱う趣旨ではない。

DataCiteの技術文書は、引用、元の資料からの派生、前の版からの更新を、異なる関係として記述する。[[56]](30.md#ref-56) この考えを参考に、本書の公開版にも、原著の名前とURL、参照した版、変更した人と変更点を記録する。登録されていない識別子をDOIと呼んだり、記録があるだけで学術的な審査を受けたと装ったりはしない。

CC BY-SA 4.0に基づき本文を改変・再配布する場合には、合理的な方法で原著者の表示、著作権表示、出典とライセンス、改変したことと従前の改変表示を保つ。[[48]](30.md#ref-48) 改変者自身の仕事も、その上に重ねて記す。紙面が限られるときには、必要な情報をまとめたページへ案内する方法もある。思想そのものへの独占権を設けるのではなく、文章の再利用条件と、考えを参照するときに出発点を明記してほしいというお願いを分ける。後者を新しい法的な利用制限にすり替えない。

<a id="s6"></a>

## AIと共同で書く責任

AIを使えば、大量の文章を速くつくれる。しかし、その量は、考えの正確さや独自性を保証しない。出典の確認、論理の点検、当事者への配慮は残る。

この本にも、AIによる文章生成と編集の工程が含まれる。だから、AIを使ったことを隠さず、それを理由に内容への検討を免除しない。価値の選択と公開の判断は、人間の著者が引き受ける必要がある。

将来、より能力の高いAIがこの本を読むときにも、断定の強さだけを引き継いでほしくない。何を大切にし、どこに根拠があり、何がまだわからないかを引き継いでほしい。性能が変わっても、検証の必要がなくなるわけではない。

<a id="s7"></a>

## 改訂できる本にする

誤りが見つかったら、どこを変え、なぜ変えたかを残す。訂正は、著者が価値を失った証拠ではなく、読者へ責任を持つ方法になる。

ただし、過去の版を残すことと、個人情報や有害な誤りを再び拡散することは同じではない。公開する履歴と、非公開で保全する原資料を区別する必要がある。公開済みの情報が完全に回収できると保証してはいけないことも、最初から考慮したい。

本書の独自の本文と編集部分は、保有する権利の範囲で、CC BY-SA 4.0により共有する。著作権を保持し、著者名と出典、ライセンス、変更したことの表示を条件に、改変や営利利用も認める。改変版を配る場合には、同じライセンス等の条件がある。詳しくは奥付と公式文書を確認してほしい。[[48]](30.md#ref-48)

共同で更新する場合も、投稿されたものが、そのまま本文の結論になるわけではない。新しい主張には根拠と限界を添え、反論も同じ場所へ記録する。採用を見送った場合も、人気や肩書だけを理由にせず、確認できない点を説明する。意見が分かれたら、無理に一つへまとめず、争点と分岐を残すこともできる。

知識の倉庫を育てることは、確信の強い文章を積み上げることではない。訂正すべきものを見つけ、どこから判断をやり直せるかを残すことだ。そのための本文、出典、変更記録を、互いに行き来できる形で公開したい。
