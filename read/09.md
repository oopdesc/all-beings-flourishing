# 第9章 共通目的と自由を両立させる

<a id="s2"></a>

## 同じ人生を選ぶ必要はない

共通目的を持つことは、全員が同じ仕事をし、同じ思想を持ち、同じ幸福を望むことではない。むしろ、違う目的を持つ人が、互いを壊さずに生きられる条件を共有することだ。

音楽に打ち込みたい人、家族と暮らしたい人、研究をしたい人、静かに日々を送りたい人がいる。これらを一つの理想的な人生へ統一する必要はない。共通に考えるべきなのは、選択の機会、安全、他者への被害、資源の分担などである。

世界人権宣言は、人の尊厳と権利に加え、思想や良心や表現の自由などを示している。[[7]](30.md#ref-7) これは宇宙の最終真理の記述ではなく、人をどのように扱うべきかについての重要な公的な基準だ。本書の共通目的も、人の自由を広げる方向で検討されなければならない。

<a id="s3"></a>

## 全員が納得する決め方はあるか

複数の人の希望を、一つの社会的な決定へまとめるのは難しい。三人が三つの案に順位をつけるだけでも、多数決の結果が循環することがある。

甲はAをBより、BをCより好む。乙はBをCより、CをAより好む。丙はCをAより、AをBより好む。二案ずつ多数決をすると、AはBに勝ち、BはCに勝ち、CはAに勝つ。どれを先に比べるかによって、結論が変わりうる。

Arrowの社会的選択の研究は、一定の望ましい条件をすべて満たす集約の難しさを、数学的に示した。[[6]](30.md#ref-6) そこから、民主主義は無意味だとも、独裁に任せるべきだとも導けない。条件の選び方と、何を犠牲にしているかを示す必要があるということだ。

Senは社会的選択について、比較に使う情報や条件を広げることによって、可能な判断も変わると論じた。[[25]](30.md#ref-25) 不可能性の結果は、問いを閉じるためだけでなく、何を変えれば前へ進めるかを探す出発点にもなる。

そのため、決め方を一つに固定するより、問題に応じて、対話、投票、専門的評価、権利による制限、試行後の見直しを組み合わせる方がよい。手続が複雑になるほど、誰にでも理解できる説明も必要になる。

<a id="s4"></a>

## 知識を持つ人と影響を受ける人

橋の安全性を評価するには専門知識が要る。しかし、橋をどこへつくり、どの地域が費用や騒音を引き受けるかは、専門家だけで決められる問題ではない。事実の評価と、利益や負担の分配を区別したい。

知識が多い人の票を機械的に重くすればよい、と本書は考えない。何を知識として認めるかを決める権力が、新しい支配になるからだ。生活の現場を知る人や、被害を受ける人の経験が、試験の得点に表れない場合もある。

専門家の役割は、証拠、予測、その限界を説明することにある。当事者の役割は、何が生活に関わり、何が受け入れがたいかを伝えることにある。両者の区別は完全ではないが、一方が他方の代わりにならないという点は重要である。

意見が一致しないときも、少数者が理由を残せること、決定を批判できること、後から訂正できることを守る。いま多数である人が、いつも多数であり続けるとは限らない。

<a id="s5"></a>

## 世界全体に一つの司令塔は必要か

全存在の幸福を考えるなら、世界を一つの管理機構へ統合する必要があるのだろうか。私は、その必然性はないと考える。すべてを一か所に集めると、誤りや濫用の影響も一か所から広がるからだ。

地域で決められることは地域で決め、広い影響を持つ問題は広く協議する。共通の最低限の保護を持ちながら、複数の実践を試せる余地を残す。このような多層的な仕組みは、違いから学ぶ可能性も保てる。

もちろん、分散すれば自動的に公正になるわけではない。地域内の権力や差別もありうる。中央への不信だけで答えを出さず、どの段階でも、説明責任、参加、救済、権力の制限を確かめる必要がある。

共通目的を持つ社会が健全であるためには、その目的の表現も批判できなければならない。著者や創設者に従うことを、善さの基準にしない。この本自体も、その例外ではない。
