# 第19章 宇宙を知ることと目的を問うこと

<a id="s2"></a>

## 観測できる宇宙と存在のすべて

宇宙を理解したいという思いは、私の思索の中心にある。なぜ何かがあるのか。時間とは何か。存在に終わりはあるのか。その問いは大きいが、大きいまま一つの答えへ急ぐ必要はない。

現在の宇宙論は、宇宙の膨張や、初期の高温で密度の高い状態、その後の変化を、観測とモデルによって研究している。[[12]](30.md#ref-12) ここで、観測によってさかのぼれる宇宙の歴史と、なぜ存在そのものがあるかという問いは、同じ範囲を扱っていない。

ビッグバンのモデルがあることから、哲学的な意味での完全な無から、すべてが生まれたと証明されたわけではない。観測可能な宇宙の外側や、最初期の状態についても、何でも自由に断定してよいわけではない。

説明の限界は、空白へ好きな答えを書き込む許可ではない。どの観測があり、どのモデルがそれを説明し、どこから先に未解決の条件があるかを分ける必要がある。

<a id="s3"></a>

## 2026年の研究が示す進み方

2026年のDESIの研究では、遠方の水素による光の吸収の相関などを使い、宇宙の膨張史やモデルのパラメータを制約している。異なるデータの組合せや、暗黒エネルギーについての仮定によって、モデルへの支持の程度も変わる。[[42]](30.md#ref-42)

ここで研究されているのは、観測量と、そこから比較できる宇宙のモデルである。宇宙が幸福を目的としているか、すべての主観が一つか、といった問いを同じデータで測ったわけではない。

最先端の研究に学びたいのは、強い結論の響きだけではない。測定の精度を示し、別の説明と比べ、系統的な誤差を検討し、追加の観測で変わりうることを明らかにする姿勢である。真理への情熱は、そのような細かな仕事によって支えられる。

なお、ここで参照したDESIの文献は、確認した版ではプレプリントである。研究集団の大きさや測定の精密さが、査読の有無や、解釈の不確実さを消すわけではない。

<a id="s4"></a>

## 秩序は熱力学に逆らっているのか

生命や文明が複雑になる一方で、エントロピーが増えるという説明を聞くと、二つは矛盾するように見えるかもしれない。しかし、局所的な秩序の形成と、周囲を含むエントロピーの増加は両立しうる。

熱力学の第二法則は、対象と周囲の区切り方が重要であり、開かれた系の一部に秩序が生じることを、そのまま禁じているわけではない。[[13]](30.md#ref-13) したがって、人間が学び、建物をつくることを、物理法則への反逆と説明する必要はない。

また、物理的な秩序と、倫理的によい社会は同じ意味の秩序ではない。厳格に管理された社会が、自由や幸福を損なう場合もある。物理学の用語から、そのまま政治的な理想を導いてはいけない。

<a id="s5"></a>

## 無限の過去と現在

「過去が無限なら、現在へ来るまで無限の時間が必要だから、現在は来ないはずだ」という考えは、直感に訴える。しかし、その一文だけで、過去が有限だと数学的に証明したことにはならない。

たとえば整数は、負の方向へいくらでも続くが、0という位置を持てる。最初の整数がないことと、ある位置が存在しないことは同じではない。この数学的な例は、現実の時間が整数列だという主張ではなく、最初がないという性質だけから、現在がないとは言えないことを示す。

実際の時間の始まりや構造を論じるには、物理理論と観測、そこで使う時間の意味を検討しなければならない。直感による疑問は重要だが、直感だけで宇宙の歴史を確定しない。

<a id="s6"></a>

## 物理法則を変えるという願い

現在できないことを可能にしたいという願いは、研究を始める動機になる。ただし、新しい装置や仕組みをつくること、自然についての理論を更新すること、自然そのものの法則を変更することは異なる。

飛行機は、重力がなくなったから飛ぶのではない。既知の条件の中で働く仕組みをつくったから飛ぶ。過去の不可能が技術によって可能になった例があっても、論理的に矛盾する願いまで、すべて実現できるという保証にはならない。

私は、理想を現在の技術だけへ閉じ込めたくない。同時に、理想の強さを、実現可能性の証拠にしたくない。何が障害なのかを分ければ、工夫で変えられる条件と、まだ何もわからない条件を区別できる。

<a id="s7"></a>

## 宇宙の目的を知らなくても

宇宙が生きているように感じられることや、全体が自己を知ろうとしているように想像することは、一つの哲学的な表現として考えられる。しかし、それが観測から確定した宇宙の目的だとは言わない。

仮に宇宙に目的があるとしても、その目的が私たちにとって望ましいかは別の問いである。自然の中で起きることを、そのまま従うべき善にすることはできない。起きることと、私たちが守りたいことを区別する必要がある。

宇宙を知ることは、私たちの可能性と限界を理解するために重要だ。それでも、宇宙の完全な答えが出る前から、誰かの苦しみに応じ、自由を守り、次の研究を支える理由は持てる。大きな謎と、今日できる配慮を、同じ人生の中に置きたい。
