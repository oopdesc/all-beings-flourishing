# 付録A 論証の見取り図

本書の結論は、一つの実験や一つの公理から出てきたものではない。以下では、経験的な知見、価値の選択、条件つきの推論、未検証の仮説を分け、どこを変えれば結論が変わるかを示す。番号は読み返すためのもので、形式検証の認証番号ではない。

<a id="s2"></a>

## 出発点となる経験と価値

**E1 経験の切実さ。** 人は、痛みや喜びや不安などを経験し、本人にとって重要なものとして報告する。個々の原因や程度については、別に確認が必要である。第1章で扱った。

**E2 判断の制約。** 人間の判断には、情報、時間、計算の制約がある。能力や結果には差があり、知性の向上だけで目的の善さが決まるわけではない。第7章、第10章で扱った。[[3]](30.md#ref-3)[[11]](30.md#ref-11)

**E3 生活の多面性。** 幸福や良好な生活は、一つの主観的な点数だけでは捉えきれない側面を持つ。何を測り、何を重視するかを区別する必要がある。第5章で扱った。[[1]](30.md#ref-1)[[24]](30.md#ref-24)[[38]](30.md#ref-38)

**V1 排除しない。** 自分から遠い、能力が違う、立場が弱いという理由だけで、他者の利益を無価値にしない。これは本書の価値の選択である。

**V2 深刻な被害を避ける。** 避けられる深刻な苦しみを減らし、生と自律を守る。苦しみの少なさだけを唯一の価値にはしない。

**V3 検討の自由を守る。** 目的の設定や変更について、影響を受ける人が理解し、参加し、異議を述べる通路を守る。

V1からV3に同意しない人へ、E1からE3だけで同意を強制できるとは主張しない。経験的な記述から価値判断へ進むには、何を大切にするかの前提が要る。

<a id="s3"></a>

## 条件つきで導くこと

**I1 他者の被害を理由なく無視しない。** V1とV2を採るなら、同種の被害について、当事者の名前が変わったという理由だけで扱いを変えることは、前提と整合しない。異なる対応には、その違いに関わる理由が必要である。第1章、第3章、第6章で説明した。

**I2 願いの全実現をそのまま仕様にしない。** 同一条件で両立しない願いや、他者への加害を含む願いがあるなら、すべてを無条件に叶える要求は採れない。V2とV3を保ちながら、目的、手段、分配を問い直す必要がある。第4章で説明した。

**I3 協力の条件を設計する。** E2があり、個別の利益と全体の利益がずれる場面があるなら、理解を深めるだけでは解けない問題が残る。負担、利益、責任、情報、見直しの仕組みを検討する。第8章、第9章、第15章で説明した。[[4]](30.md#ref-4)[[5]](30.md#ref-5)[[43]](30.md#ref-43)

**I4 目的も更新の対象にする。** E2とV3を採るなら、現在の目的の記述や判断者を、訂正できない権威にしない方がよい。修正の理由と責任を明らかにし、検討の通路を残す。第10章、第14章、第21章で説明した。

**I5 行動の前後を確かめる。** E2とE3があり、V1とV2を採るなら、善意や平均値だけで成功と認定せず、影響の違いと不利益を確認する必要がある。第5章、第16章、第17章、第22章で説明した。

ここから、本書の暫定的な共通目的を提案する。配慮から排除される存在を減らし、深刻な被害を避け、各人が自分の生を選び直せる条件を、協力して広げる。この提案は、価値前提と経験的な条件を伴う。宇宙から一義的に導かれた命令ではない。

<a id="s4"></a>

## 結論を支えるために必要ではない仮説

**H1 主観の根底の同一性。** すべての主観が根底では同じ主体なのかは、本書で科学的に確定していない。この仮説に賛成しなくても、V1とV2から他者への配慮を考えられる。第6章で扱った。[[34]](30.md#ref-34)

**H2 宇宙全体の自己超越。** 生命や文化に変化があることから、宇宙全体の意志や、幸福へ必ず向かう法則は導かれない。第14章、第19章で扱った。

**H3 人工システムの経験。** AIの能力や自己報告だけから、主観的な苦痛や喜びを確定しない。理論、内部機構、評価の校正などに課題がある。第11章、第18章で扱った。[[36]](30.md#ref-36)[[39]](30.md#ref-39)[[40]](30.md#ref-40)[[41]](30.md#ref-41)

**H4 最終真理と最終目的。** 存在に究極の目的があるか、その問いが適切に立てられているかは未解決である。未解決であることを、あらゆる想像が同じ程度に確からしいという意味にはしない。第19章、第24章で扱った。

これらの仮説の一つが変わっても、日常の配慮と研究の必要がすべて消える構成にはしていない。大きな仮説と実践的な理由を、このように部分的に独立させることが、本書を更新しやすくする。
