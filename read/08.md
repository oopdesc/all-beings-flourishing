# 第8章 協力できる条件をつくる

<a id="s2"></a>

## 協力は善意だけでは続かない

一人で解決できない問題を、複数の人が分担して解く。病気を調べる研究、道路の維持、知識の蓄積、災害への対応。私たちの生活には、誰かとの協力を前提にした仕事がある。

しかし、協力が全体に利益をもたらすことと、各人が協力する理由を持てることは別だ。自分が費用を出さなくても結果を利用できるなら、出さない方が得になる場合がある。協力した人だけが疲れ、協力しない人も同じ利益を得る仕組みでは、善意に負担が集中する。

進化における協力を整理したNowakの論文は、血縁、互恵性、相互作用の構造など、協力が成立する複数の仕組みを扱っている。協力を、無条件に生じる性質としてではなく、成立条件を持つ現象として考えるための研究である。[[4]](30.md#ref-4)

2026年6月のAndreらの研究は、125か国、101,123人を対象にした報酬を伴う二人の協力実験で、69％が協力を選び、他者の協力への期待が実際より低い傾向を報告した。[[37]](30.md#ref-37) この実験では、私的な受取りを一部減らす選択を両者がした場合、気候対策への寄付が行われる。そこで観察されたのは、その利得と寄付先と説明の下での選択である。現実の紛争や長期の共同事業が同じ割合で解けることや、全員が一つの価値観を持つことを示したわけではない。

この研究が、そのまま人間社会の制度を一つに決めるわけではない。生物の進化で起きることが、そのまま倫理的に望ましいとも限らない。それでも、「みんな協力すべきだ」と呼びかけるだけでなく、協力を支える条件を調べるという姿勢は重要だ。

<a id="s3"></a>

## 共通目的があっても残る問題

同じ目的を掲げる組織でも、対立は起こる。目的の解釈、費用の分担、成果の受け取り方、急ぐ程度が違うからだ。また、共通目的に賛成していても、担当する作業や、使える時間は同じではない。

たとえば、地域の学習会を続けたい人が十人いたとしても、一人だけが会場を取り、資料をつくり、後片づけをすれば、やがて続けられなくなる。全員が同じ目的を口にすることは、負担の公平さの代わりにならない。

この場合、仕事を見えるようにし、参加できる範囲を確かめ、役割を交代し、必要なら活動自体を小さくする方がよい。「目的が大切なのだから我慢してほしい」と言うだけでは、共同の活動が一人の犠牲に依存してしまう。

協力に参加しない理由にも違いがある。利益だけを受け取りたい人と、生活に余裕がない人、情報が届いていない人、過去に不利益を受けて警戒している人を、同じように扱わない。理由を確かめなければ、制度は弱い人から排除する方向へ進みかねない。

<a id="s4"></a>

## 一つの制度を万能薬にしない

Ostromは、環境や資源の管理を、どこでも同じ制度で解決しようとする考えを批判し、状況に応じて制度と条件を診断する枠組みを示した。[[5]](30.md#ref-5) 共有か私有か、国家か市場かという一つの分類だけでは、実際の違いを十分に扱えない。

本書も、資本主義をなくせばすべて解決する、あるいは市場に任せれば必ずよくなる、という答えは採らない。価格による調整が役立つ場面も、公共サービスや共同管理が重要な場面もある。どの仕組みが、誰のどの利益を守り、誰にどの負担を与えるのかを調べる方がよい。

競争についても、すべてを争いと同一視しない。ルールが公正で、参加が自由で、敗者の生活が壊れないなら、競争が技能や発想を育てることはありうる。一方、地位や生存を賭けた競争が、隠蔽や消耗を生む場面もある。競争の有無より、その条件と影響を確かめたい。

誰かが豊かになれば、必ず別の誰かが同じだけ貧しくなるという関係も、すべての経済活動に当てはまるわけではない。新しい価値が生まれることもある。ただし、その価値が誰に渡り、費用が誰に押しつけられたかは別に問う必要がある。

<a id="s5"></a>

## 協力の設計で確認すること

協力を始めるときは、まず何を一緒に行い、何は各人に任せるのかを明らかにする。次に、必要な情報と仕事を見えるようにし、負担と利益を説明する。決め方と、困ったときの相談先も決めておく。

さらに、結果を確認する時点を設ける。参加者だけが満足していても、外部に被害が出ているかもしれない。参加していない人や、声を上げにくい人への影響も確かめる。うまくいかなければ、理由を調べ、縮小や中止を選べるようにする。

この設計は、人間への不信だけから生まれるものではない。善意がある人にも限界があり、善意だけに頼る組織では、その人が疲れたときに全体が崩れるからである。協力を続けるには、協力する人を守る必要がある。

共通目的は、こうした仕組みの方向を与える。仕組みは、目的を日々の行動へ変える。目的と仕組みのどちらか一つでは足りない。その関係を、後の数理モデルでもう一度確かめる。
