# 第23章 この提案に反論する

<a id="s2"></a>

## 幸福を共通目的にすること自体が支配ではないか

この反論は重要だ。人には、幸福よりも真実や忠実さや創造を重んじる場合がある。外から幸福の定義を決め、それへ全員を向かわせるなら、本書も支配の思想になりうる。

したがって、本書の提案は、すべての生を快い気分へ揃えることではない。本人が価値を考え、選び、異議を述べられる条件を含める。また、「全存在の幸福」という表現より適切な共通の表現が見つかれば、それも検討すべきだ。

ここで守りたいのは、誰かの生を、他者の計画の材料だけにしないことである。目的の言葉がその原則を妨げるなら、言葉の方を変える必要がある。

<a id="s3"></a>

## 既存の思想を言い換えただけではないか

他者の苦しみを重視すること、公平な分配、自由、相互の正当化、自己の捉え直しは、本書が初めて考えたことではない。長い哲学の伝統と、現代の研究がある。

たとえば、Scanlonの著書は、私たちが互いに何を負うかを、理由と正当化の問題として論じる。[[33]](30.md#ref-33) Senの研究は、社会的選択で何の情報を比較するかを問い直す。[[25]](30.md#ref-25) 自己の同一性を開かれたものとして考える哲学もすでにある。[[34]](30.md#ref-34)

それらを無視して、新しい名前をつければ独創的だという態度は採らない。本書の仕事は、既存の答えと未解決の問いを、苦しみへの配慮、目的の更新、宇宙への探究という流れの中で結び、読者が使い、直せる形にすることにある。

この結び方が唯一でも、最善でもあると証明されたわけではない。価値は、読者が前提を追え、誤りを見つけ、次の探究へ進めるかによっても評価される。

<a id="s4"></a>

## 人間が協力するという見通しは楽観的すぎないか

協力できる可能性があることと、全員が必ず協力することは違う。相手が加害をやめず、話し合いが成立しない場合もある。利害の衝突、資源の不足、権力の偏りを、対話の不足だけで説明することはできない。

そのため、本書は、善意の呼びかけとともに、被害の防止、権限の制限、責任、救済、退出の自由を重視する。協力を目指す人が、協力しない人によって無制限に利用される構造では、共通目的そのものが続かない。

同時に、すべての人を最初から敵対的だと想定すると、可能な協力を失うかもしれない。2026年の国際実験が示した、協力と他者への期待のずれは、その想定を検討する材料になる。[[37]](30.md#ref-37) ただし、一つの結果に万能の希望を預けず、場面ごとの証拠を使う。

<a id="s5"></a>

## 他者を大切にする理由に同意しない人にはどうするか

私が、公平さや苦しみへの配慮を大切にしていても、全員が同意するとは限らない。その人へ、数学のように必ず承認させられる最終証明を、私は持っていない。

それでも、互いに被害を受けない利益、予測できるルール、関係を維持する利益など、別の理由から協力が成立することはある。同じ最終的な哲学を共有しなくても、具体的な行為について合意できる可能性がある。

合意できない部分が残るなら、その違いを認めながら、加害を制限し、権利を守る必要がある。倫理の根本問題が解決していないことは、何でもしてよいという許可にはならない。少なくとも、社会で採るルールと、その正当化についての議論は続けられる。

<a id="s6"></a>

## 全存在という範囲は広すぎないか

未知の宇宙や、無数の将来の存在まで数え始めると、目の前の行動が決まらなくなるかもしれない。想像上の巨大な利益が、いまの人の権利を押し流す危険もある。

本書は、証拠のない無限の利益を、有限の現実の被害より必ず重く見る計算を採らない。現実に確認できる生活、深刻で差し迫った被害、将来に残る取り返しのつかない影響を、理由を示しながら検討する。

また、将来の人口を増やすことや、経験の総量を増やすことを、自動的に最上位の目的にしない。誰のどの生活をよくするのか、同意と分配をどう扱うのかという問いを残す。存在の数だけで、個々の生の意味が決まるわけではない。

<a id="s7"></a>

## この思想が間違っていたらどうするか

その可能性は残る。前提の一部が不適切かもしれないし、言葉の広さが実際の判断を妨げるかもしれない。実践した方法が、予想に反して負担を増やすかもしれない。

そのときは、思想の名誉を守るために人を犠牲にせず、被害への対応と修正を優先する。目的を大切にすることと、現在の表現を何があっても守ることは違う。

この本を足場にするとは、この本の上へ同じ方向に積み続けることだけではない。弱い部分を外し、別の足場へ移ることも含む。その自由を渡せなければ、自己超越を語る本として、一貫していない。
