# 第20章 数学が保証することと保証しないこと

<a id="s2"></a>

## 記号を増やす前に意味を決める

数学は、前提と関係を明確にするために役立つ。何を変えたときに何が変わるのか、どの条件が同時には満たせないのかを、言葉だけより追いやすくする場合がある。

しかし、「意識」「幸福」「宇宙の目的」といった言葉を変数の名前にしただけでは、それらを測れるようになったわけではない。変数と現実の対応、値の決め方、単位、予測、誤差を示さなければ、計算は記号の中に留まる。

乱数でつくったデータにきれいな曲線が出ても、それは現実の意識や幸福を説明した証拠ではない。シミュレーションは、仮定から何が起こるかを調べる方法であり、その仮定が世界に合っているかは、別に確かめる必要がある。

<a id="s3"></a>

## 矛盾と未解決は違う

まだ答えがわからないことと、二つの条件が論理的に両立しないことは違う。前者には、情報を増やすことが役立つかもしれない。後者には、条件や定義を変える必要がある。

同じ意味、同じ時点、同じ条件で、ある事柄が成り立つことと、成り立たないことを同時に要求したら、通常の古典論理では満たせない。もっと賢い存在なら必ず両方を満たせると言っても、その主張には別の論理や意味づけが必要になる。

一方、矛盾して見えるだけで、言葉の意味が違ったり、時点が違ったりする場合もある。その場合は、条件を明らかにすることで解ける。「すべては矛盾を含む」という大きな表現で、個別の違いを曖昧にしない方がよい。

<a id="s4"></a>

## 不完全性定理から言えること

Gödelに始まりRosserが強めた第一不完全性定理は、十分な算術を表せる、無矛盾で効果的に公理化された形式体系に関して、その体系内で証明も反証もできない文があることを示す。[[14]](30.md#ref-14)[[47]](30.md#ref-47) どのような体系を対象にしているかという条件が重要である。

そこから、宇宙には完全なものが何もないとか、無は存在しないとか、人間は必ず機械を超えると、そのまま結論することはできない。数学の結果を別の領域へ移すなら、対象がその条件を満たすことと、結論が何を意味するかを示す必要がある。

知識に限界があるという姿勢は大切だが、姿勢を支えるために、定理の意味を広げすぎる必要はない。むしろ、正確な条件の下で強い結論を出すことが、数学から学べる重要な点である。

<a id="s5"></a>

## 形式的な証明と世界の正しさ

形式的な検証は、決めた定義や公理から結論が導かれるかを確認する。人間の見落としを減らす力がある。しかし、現実の生活を適切に表しているか、倫理的な前提が正当かは、形式化の外にも検討を必要とする。

たとえば、全員の幸福を足した数を最大にするプログラムが、正しく動くと証明されたとする。それでも、その幸福の測り方が不適切なら、正しく間違った対象を最大化しているだけになる。正しい実装と、正しい目的を区別しなければならない。

本書の数理的な説明は、限られた仮定の下の論証と、再現可能な小さな計算例である。機械による形式検証を済ませた普遍倫理の証明ではない。形式化できる部分を明確にしながら、形式化の外に残る判断も見えるようにしたい。

<a id="s6"></a>

## 未知を尊重する仕方

わからないことを認めると、何も言えなくなるように感じるかもしれない。しかし、未知の範囲がわかるほど、次に調べることを絞れる。意味を定義する必要があるのか、測定方法をつくる必要があるのか、競合する説明を比べる必要があるのかが見えてくる。

私は、問いの大きさを失いたくない。同時に、大きな問いの下へ、未確認の計算や権威の名前を積み重ねることも避けたい。何を知ったのかを、小さくても確かに言えることが、次の探究の足場になる。
