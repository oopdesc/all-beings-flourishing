# 第2章 事実と価値をつなぐ

<a id="s2"></a>

## 同じ文の中に違う仕事がある

「人は他人の協力なしでは暮らせない。だから、すべての人を大切にするべきだ」。自然に読める文だが、前半と後半では仕事が違う。前半は人間の生活についての説明であり、後半はどう行動するかについての提案である。

相互依存しているという事実だけから、必ず互いを大切にする義務が出るわけではない。同じ事実を見て、「ならば他者を利用した方が得だ」と考える人もいる。前半から後半へ進むには、相手の生も尊重する、利益だけでなく被害も考慮する、といった価値の前提が必要だ。

この前提を隠すと、科学が倫理を一つに決めたように見える。前提を示せば、読者は、どの部分に同意し、どの部分に疑問があるのかを言える。議論を続けるためには、その方が役に立つ。

本書は、事実から価値を切り離して無関係にするのでもない。たとえば、苦しみを減らしたいという価値を選んでも、どの支援が有効かは、観察や研究なしではわからない。価値は調べる方向を与え、事実は手段と予想を修正する。両者は混ぜずに結びつけられる。

<a id="s3"></a>

## 四つの問いで主張を点検する

何かを主張するとき、まず「その言葉は何を意味するか」と問う。幸福と言いながら、快楽、満足、達成、安心、自由を場面ごとに入れ替えていたら、議論はつながらない。すべてを一つに定義する必要はないが、どれを論じているかは示す必要がある。

次に「それを信じる理由は何か」と問う。自分の経験なのか、他者の報告なのか、調査なのか、数学的な証明なのか。それぞれに強みと限界がある。一人の経験は、その人に起きたことを理解する重要な資料だが、人類全体で同じことが起きる証明にはならない。

さらに「別の説明はあるか」と問う。ある学習法を使った人の成績がよかったとしても、学習法の効果だけとは限らない。もともと学ぶ意欲の高い人がその方法を選んだのかもしれない。時間や指導者や環境が違った可能性もある。

最後に「何がわかれば考えを変えるか」と問う。どんな結果が出ても自分の理論が正しいと言えるなら、その理論は少なくとも、その結果によっては試されていない。思想として持つ自由はあるが、実験で支持されたと呼ぶには別の条件が要る。

この四つの問いは、相手を論破する道具だけではない。自分の大切な考えを、他者が検討できる形にするための問いである。

<a id="s4"></a>

## 論理が正しくても前提は間違いうる

「すべての人は同じ願いを持つ。全員が同じ願いを持つなら、願いは衝突しない。したがって願いは衝突しない」。推論の形が整っていても、最初の前提は現実に合わない。また、同じ願いがあっても、同じ一席を全員が欲しがるなら衝突する。言葉の形と、前提の内容を別々に確かめなければならない。

証明とは、前提と規則を決めたうえで、結論までの移り方を確かめる作業だ。証明支援ソフトを使えば、その移り方を厳密に確認できる場合がある。しかし、現実の幸福が本当にその変数で表せるのか、当事者がその前提を受け入れるのかまでは、ソフトが自動的に保証するわけではない。

本書の論証も同じ制約を持つ。どこからでも真理を取り出せる万能の鎖をつくることはできない。代わりに、どこに経験的な根拠があり、どこに価値の選択があり、どこに条件があるかを追える鎖をつくる。

<a id="s5"></a>

## 科学になっていく問い

哲学の問いの一部は、定義や測定方法が整うことで、経験的な研究へ進む。心とは何かという大きな問いから、注意や記憶や知覚の個別の研究課題が取り出される。だから、いま観測できないからといって、考えることが無駄になるわけではない。

ただし、数値をつければ科学になるわけでもない。「意識の深さ」を十段階で自分が評価しても、その数字が何を測っているのかが不明なら、謎に数字を貼ったにすぎない。測定の安定性、別の方法との関係、他の説明との区別を検討する必要がある。

科学の範囲を広げるとは、未知のことを既知と宣言することではない。以前は一つの大きな言葉でしか語れなかった問題を、小さな問いに分け、何を観察すればよいかを明らかにすることだ。そのための具体例を、第15章から第20章で示す。
