# 付録D 既存研究を読むための案内

本書の文献調査の基準日は2026年10月26日である。これは関連性を優先した選択的な調査であり、世界中の文献を網羅した系統的レビューや、新しいメタ分析ではない。主張の強さは、刊行年や掲載誌の名前だけでは決まらない。

<a id="s2"></a>

## 幸福とよい生活

最初に、第5章の測定の区別を確認する。その後、OECDの指針と、Global Flourishing Studyの初期報告、2026年の多面的な比較を読むとよい。[[1]](30.md#ref-1)[[24]](30.md#ref-24)[[38]](30.md#ref-38) 何を幸福に含めるかという概念上の選択と、回答や生活条件のデータを分けて見る。尺度の規範的な前提への批判も並べて読みたい。[[45]](30.md#ref-45)

国や集団の平均を、その中のすべての人の特徴と考えない。関連が見つかっても、原因が決まったとは限らない。質問の翻訳、対象の選び方、調査時点、欠測や脱落なども、結果の意味に関わる。

<a id="s3"></a>

## 協力と制度

2026年の国際的な協力実験を読むときは、選択肢、報酬、相手についての情報を確かめる。[[37]](30.md#ref-37) そこから実際の共同事業へ進むには、期間、責任、資源、関係の違いを検討する必要がある。

Ostromの診断的な制度研究と、社会的ジレンマの整理を合わせると、個人の気持ちと、利益の構造を分けて考えられる。[[5]](30.md#ref-5)[[43]](30.md#ref-43) 特定の制度を万能薬にしないという観点を持ちたい。

<a id="s4"></a>

## 社会的な選択と正当化

Arrowの結果は、定理の前提と結論を分けて読む。[[6]](30.md#ref-6) 次にSenの議論を読むと、比較に使う情報を変えることで、何が可能になるかという方向が見える。[[25]](30.md#ref-25)

公平さについては、平等と優先を区別する議論、個人へ理由を示すことを重視する議論がある。[[32]](30.md#ref-32)[[33]](30.md#ref-33) 本書はそれらを一つの立場へ完全に統合したとは主張しない。何を評価単位とし、誰の異議をどう扱うかを比べる。

<a id="s5"></a>

## 倫理的な不確実さ

Moral Uncertaintyは、何が正しいかについての不確実さを、判断へどう反映するかを論じる。[[28]](30.md#ref-28) それに対して、異なる理論の評価を期待値へまとめることへの批判もある。[[29]](30.md#ref-29)

ここでは、提案を読んだ後に反対論も読み、反対論を読んだ後に、何がまだ可能かを考えるとよい。どちらかの題名を、そのまま最終結論にしない。

<a id="s6"></a>

## AIと人間の学習、価値の集約

第10章の学習研究は、支援がある最中の成果と、支援を外した後の理解を分けて読む。[[49]](30.md#ref-49)[[50]](30.md#ref-50)[[51]](30.md#ref-51) 教材、対象、試験までの時間が違う結果を、同じ効果の単純な再現とは扱わない。

価値を集約する総説から原著へ進む際には、何を効用と定め、比較データがどう得られたかを確認する。[[52]](30.md#ref-52) 先行する解析と後続する解析で条件が違うときは、結論の強さだけを比べない。[[53]](30.md#ref-53)[[54]](30.md#ref-54) 数学上の保証と、どの価値を採るかという判断を区別したまま読む。

<a id="s7"></a>

## AIの意識

2026年の指標に関する論文、内部の機能を調べるプレプリント、指標の校正と転用を問う論考、デジタルAIの意識に懐疑的な論評を、種類を分けて読む。[[36]](30.md#ref-36)[[41]](30.md#ref-41)[[39]](30.md#ref-39)[[40]](30.md#ref-40)

ここで確認したいのは、対象のシステム、理論上の前提、観測された機能、その機能から経験へ進む推論である。論文が示したことより、見出しの方が強くなっていないかにも注意する。

<a id="s8"></a>

## 配慮を調べる研究の段階

2026年の複数水準の思いやり研究は、新しい見方と測定案の提案として読む。[[46]](30.md#ref-46) 提案された指標の名前があることと、その妥当性や効果が実証されたことは違う。構想、測定法の開発、検証、実践の効果を分けて追うとよい。

<a id="s9"></a>

## 宇宙についての研究

宇宙論では、何を観測し、どのモデルを仮定し、何のパラメータを制約したかを読む。第19章で参照した2026年のDESIの研究も、そのような観測とモデルの比較である。[[42]](30.md#ref-42)

モデルに未解決の点があることは、宇宙の意志や究極目的が確認されたことではない。わからないことを、別の大きな断定の根拠へ変えない。そのうえで、未解決の点から新しい問いを立てる。

<a id="s10"></a>

## 自分の読書記録をつくる

一つの文献を読んだら、問い、方法、結果、限界、本書との関係を、それぞれ短く記す。本文、要旨、出版社の紹介のどこまで確認したかも残す。題名を見ただけなら、そのことを明記する。

引用したい主張については、元の資料の該当箇所を確認する。別の論文が紹介した内容を、原著を読んだかのように扱わない。研究に反論がある場合も、反論の存在だけで元の研究が無価値になったとは考えず、争点を特定する。

こうした読書記録があれば、将来の読者やAIは、本書を盲目的に引き継ぐ代わりに、何をもう一度確かめるべきかを知ることができる。
