# 付録C 次の研究を設計する

以下は、実施済みの研究ではなく、問いを検証可能にするための計画例である。既存研究と重なる部分は、まずその研究を読み、再現や拡張が本当に必要かを判断する。人を対象にする研究を、ここに書いたという理由だけで実施してよいわけではない。

<a id="s2"></a>

## 共通目的の話し合いを調べる

問いを、「目的、負担、異議の出し方を共同で確認する手続が、作業理解と負担の偏りをどう変えるか」に絞る。比較対象は、同じ時間を使い、同じ作業を説明するが、その共同確認を行わない手続などが考えられる。何と比べた効果なのかを、明確にする。

主要な指標は、作業の目的と役割を正しく説明できた割合とする案がある。ただし、研究前に採点基準を定める。実際の負担の分布、参加のしやすさ、満足度、不利益は、別の指標として記録する。

予測は、単に「よくなる」とせず、どの指標が、どの期間に変わるかを定める。反対に、説明の時間だけ増えて負担が偏る、少数意見が言いにくくなる、といった失敗の可能性も記す。結果が予測に合わなければ、目的の共有の方法や、作用の説明を見直す。

無作為割当てが適切か、集団単位で扱う必要があるか、集団間に情報が伝わるかを検討する。人数は効果の検出だけでなく、不利益や脱落の見積りを含めて設計する。先に主要な分析と、探索的に見る分析を分けておく。

<a id="s3"></a>

## 他者への期待と協力を調べる

2026年の国際実験を起点に、他者への期待が実際の協力とどう関わるかを読む。[[37]](30.md#ref-37) 新しい場面で調べる場合も、論文の結論を、そのまま使える宣伝文句にしない。

情報提供を行うなら、内容が事実で、対象の条件に合っていることが必要だ。望ましい行動を引き出すために、他者の協力率を捏造してはいけない。情報への理解、期待の変化、行動の変化を分けて測る。

また、協力を選ばなかった人を、道徳的に劣る人として評価しない。実験上の選択、生活の制約、思想への賛否は違う。集めた情報を、雇用や成績など、本人が同意していない評価へ転用しない。

<a id="s4"></a>

## 意識の仮説を研究へ近づける

「すべての主観は一つか」という問いを科学的に試すには、その仮説と別の仮説で、異なる観測結果が予測される必要がある。現時点で、その違いを示していないなら、観測によって支持されたとは言えない。

一方、言語報告に使われる表現が、内部のどの処理へ利用されるか、理論由来の指標がどの条件で安定するかなどは、より具体的な研究課題になりうる。[[36]](30.md#ref-36)[[39]](30.md#ref-39)[[41]](30.md#ref-41) ただし、それらの機能を調べることと、現象的な経験の有無を確定することは、分けて記述する。

新しい研究を提案するときは、何を見つけたら何を言えるかだけでなく、見つけてもなお何を言えないかを、先に書く。この一文が、研究と願望の境界を守る。

<a id="s5"></a>

## 結果を報告する際の最低限

問いと事前の予測、対象と選び方、比較、測定方法、実施期間、欠測や脱落、分析方法、効果の大きさと不確実さ、不利益、限界を示す。研究後に説明を変えたなら、その変更も示す。

有意な結果だけを報告せず、うまくいかなかった条件を残す。個人を特定しない形で、可能な範囲の資料と分析を共有する。共有できない情報は、その理由を記す。未実施の計画を、成果として先に宣伝しない。

この計画が目指すのは、倫理の最終真理を実験一つで決めることではない。共通目的を実際の手続へ変えたとき、何が起こるかを、他者が確かめられるようにすることである。
