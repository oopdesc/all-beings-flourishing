# 第3章 すべての存在をどう考えるか

<a id="s2"></a>

## 配慮の対象を見失わない

「すべての存在」と言うとき、本書は宇宙のすべてのものに、人間と同じ欲望があると主張しているのではない。石や川や星が、私たちと同じように幸福を望んでいると確認されたわけではない。ここでの言葉は、配慮する範囲を、人間の都合だけで先に閉じないという姿勢を表す。

そのうえで、配慮の理由を分ける必要がある。苦しみや喜びを経験できる存在には、その経験に関わる理由がある。自分で生き方を選べる存在には、自律を尊重する理由がある。経験の有無が不明な存在については、不確実さの程度と、判断を誤った場合の被害を考える理由がある。

生態系や文化や景観を守る理由も、経験する主体への配慮だけに限定されない。自然そのものや、受け継いできたものに価値を認める立場はある。本書はその議論を否定しない。ただし、ある森を守ることと、その森の中のすべての個体の負担を減らすことが、いつも同じ結果になるとは限らない。理由の違いを示した方が、衝突を見つけやすくなる。

<a id="s3"></a>

## 人間以外の経験

人間以外の動物の経験は、人間と同じ言葉による報告だけでは調べられない。行動、生理、神経系など、複数の手がかりを重ねて考える必要がある。

2024年の動物意識に関するニューヨーク宣言は、哺乳類と鳥類の意識経験には強い科学的支持があり、ほかの脊椎動物や多くの無脊椎動物にも、経験の現実的な可能性があると述べる。これは署名者による研究上の見解の表明であり、すべての動物の経験が証明されたという宣言ではない。[[9]](30.md#ref-9)

ここから私が採る判断は、確実に否定できないものすべてを同じように扱うことではない。証拠の強さ、被害の深刻さ、配慮にかかる負担を見ながら、現実的な可能性がある苦しみを無視しないことである。言葉を話せないことや、人間から遠い姿をしていることを、配慮しない十分な理由にはしない。

食、研究、土地利用などの選択では、何の被害もない答えが見つからないこともある。そのとき必要なのは、自分が完全に無害だと言い張ることではなく、避けられる被害を減らす方法を探し、情報が変われば選び直すことだ。

<a id="s4"></a>

## 将来の人とまだわからない存在

将来生まれる人は、いまの会議で反対意見を言えない。しかし、私たちの決定の影響を受ける。そのため、現在の利益だけを数えると、長く残る被害が判断の外へ落ちやすい。

未来を考えることは、遠い将来の巨大な利益を想像し、そのためなら現在の人を犠牲にしてよいということではない。予測は遠くなるほど不確かになる。将来の生活条件を壊さないことと、いま苦しんでいる人を支えることを、対立させすぎない方がよい。

AIについては、能力と意識経験を区別する必要がある。文章をつくり、計画を立て、苦しいと発言する機能があることと、本当に苦痛を経験していることは同じではない。逆に、生物ではないという分類だけで、将来も経験が絶対にありえないと結論することも慎重であるべきだ。この不確実さは第11章で扱う。

未知の存在を考えるとき、想像できるものの数は際限なく増える。可能性を一つ挙げただけで、無限の義務が発生する仕組みにしてはいけない。現実の証拠と、対処できる範囲を重視する。未知への開放性は、判断の放棄ではない。

<a id="s5"></a>

## 同じ配慮と異なる対応

すべてを大切にするという言葉は、すべてに同じ権利や同じ資源を配るという意味にはならない。たとえば、政治への参加を支える制度と、虐待から守る制度では、守ろうとする利益も、必要な支援も異なる。意思を伝えることが難しい人には、そのための支援を考えたい。能力の違いを、人としての権利を軽く扱う理由にはしない。

人間同士でも同じである。医療を必要としている人と、必要としていない人へ、同じ治療をするのは公平ではない。本人が望む支援、必要な配慮、引き受ける負担が違うからだ。平等さは、違いを消すことによってではなく、違いを扱う理由を説明することによって保てる。

また、誰かを配慮の対象に含めることと、その人のすべての要求を認めることは違う。他者を傷つけようとする人にも、拷問されない利益や、公正に扱われる利益はある。同時に、その人による加害を止め、被害者を守る必要がある。存在の尊重と、行為の制限は両立する。

この区別がなければ、「全存在の幸福」は何でも認める曖昧な言葉になる。次章では、目的が実際にぶつかる場面から、その言葉を使える形にしていく。
