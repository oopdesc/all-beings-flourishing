# 第16章 公平な判断を数字だけで決めない

<a id="s2"></a>

## 合計が大きければよいのか

三人に影響する、三つの案を考える。A案の評価は、甲が10、乙が10、丙がマイナス2。B案は、三人とも5。C案は、甲が4、乙が7、丙が6とする。ここでも数字は架空であり、実際の幸福を共通の物差しで測れたと仮定した説明用の値である。

合計だけを比べると、A案は18、B案は15、C案は17なので、A案が選ばれる。しかし、丙にとってのマイナス2が、深刻な権利侵害を含むなら、合計の大きさだけでは受け入れられない。

そこで、最低限守る条件に反する案を、最初に検討の対象から外すという方法がある。仮に、この例では全員の評価が0以上であることを最低条件と決めれば、A案は外れ、B案とC案が残る。

ただし、0という境界は自然から発見された倫理ではない。この例のために置いたルールである。現実の最低基準は、法、権利、当事者の意見、被害の性質を考慮して決めなければならない。数字の見た目によって、その判断を隠してはいけない。

<a id="s3"></a>

## 最も不利な人を見るか合計を見るか

残ったB案とC案のうち、合計を大きくするならC案になる。一番低い評価をできるだけ高くするなら、B案になる。どちらを選ぶかは、計算ミスの有無だけでは決まらない。

B案からC案へ変えると、甲は5から4へ下がり、乙は5から7へ、丙は5から6へ上がる。誰も悪くならず誰かがよくなるという変更ではない。改善と負担の両方がある。

Parfitの平等と優先についての議論は、差があること自体を問題にする立場と、不利な状態の人への利益を重く見る立場を区別する。[[32]](30.md#ref-32) それらの違いを、単に「みんなのため」という言葉だけで消してはいけない。

また、最低の状態だけを見れば、それ以外の大きな改善を見落とす場合もある。合計を見れば、少数者の深刻な負担を見落とす場合がある。だから本書は、一つの計算式を万能の倫理として提示しない。どの基準を使い、何を見なくなるかを説明する。

<a id="s4"></a>

## 比較できる部分と比較できない部分

二つの案を比べたとき、全員が同じかよくなり、少なくとも一人がよくなるなら、一般にパレート改善と呼ばれる。この意味の改善が可能なら、その案を検討する理由は強い。

ただし、何をよくなったとするか、外部の人への影響を数えているか、将来への負担がないかを確かめる必要がある。見えている三人の間で改善しても、別の人へ被害を押しつけていれば、全体についての改善とは言えない。

また、パレート改善が残らない状態でも、配分が公正とは限らない。非常に偏った状態でも、誰かを悪くせずに改善できないことはある。効率的であることと、公平であることは別の性質である。

こうして比較できる部分を確かめ、比較が決まらない部分は、当事者を交えた価値判断として扱う。決まらないことを隠すより、どこが決まらないかを示す方が、次の議論へ進める。

<a id="s5"></a>

## 予測にも不確実さがある

現実には、各案の評価そのものが不明である。ある案が生活を改善する予測にも、誤差や、見落とした影響がある。都合のよい一点だけを選んで、最適な案と宣言してはいけない。

たとえば、甲への影響が1から3の改善、乙への影響がマイナス1から2の範囲と予測されるなら、全員が必ずよくなるとは言えない。乙への悪影響がありうる。その不確実さを減らす調査や、小規模な試行に価値があるかもしれない。

予測だけでなく、何をよいとするかにも不確実さがある。道徳的な不確実さを意思決定で扱う研究には、複数の倫理理論を考慮する提案がある。[[28]](30.md#ref-28) 一方、異なる理論の評価を共通の尺度で扱うことへの批判もある。[[29]](30.md#ref-29) 本書は、その議論が一つの公式で解決したとはみなさない。

<a id="s6"></a>

## 決めることと訂正できること

不確実だから永遠に何も決めない、というわけにもいかない。何もしないことも、結果を持つ。したがって、現在の証拠に基づいて選び、誤りが見つかったときの対応を、選ぶ時点で用意しておく。

誰が影響を確認するか。被害が出たら、どの条件で止めるか。困った人が、どこへ訴えられるか。最初の約束が果たされなかったら、誰が説明するか。これらは、計算の後の付け足しではなく、判断の一部である。

すべての存在の幸福を考えるとは、すべての情報を持つ一人の計算者になることではない。自分の計算から落ちた人が、もう一度入ってこられる通路をつくることである。
