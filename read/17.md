# 第17章 理想を検証可能な問いに変える

<a id="s2"></a>

## 何を確かめたいのかを狭くする

「共通目的は世界をよくする」という主張は大きすぎて、そのままでは何を調べればよいか決まらない。まず、どの集団で、何を共有し、何と比較し、何が変わると予想するかを分ける必要がある。

たとえば、「共同作業の前に、目的と負担と異議の出し方を話し合うと、話し合わない場合より、参加者の理解と負担の公平感が改善するか」と問うことはできる。これは、宇宙の最終目的を証明する問いではない。限られた条件で、具体的な手続の効果を確かめる問いだ。

すでに関連する研究があるなら、新しい実験を思いつく前に読む。どこで何がわかり、何が再現されていないのかを確認する。似た言葉を使っていても、測っているものが違えば、同じ研究とは言えない。

<a id="s3"></a>

## 好感と行動と制度を分ける

対立する集団の相手に好感を持てるようになれば、民主的な行動もよくなるのだろうか。関連するかもしれないが、一つが変わればすべてが変わるとは限らない。

2024年の大規模な研究は、米国の党派的な敵意や反民主的な態度を減らすための25種類の介入を比較した。[[30]](30.md#ref-30) 一方、2025年の研究は、敵意を減らす介入の効果の大きさや持続、ほかの民主的な態度への波及に限界があることを検討している。[[31]](30.md#ref-31)

これらから、「対話は無意味だ」とも、「好感を上げれば政治の問題が解ける」とも結論しない。対象、介入、測定時点、結果指標を区別する。米国の党派についての研究を、あらゆる国や職場や宗教の対立へ、そのまま移すこともしない。

共通目的についても同じである。言葉への賛成、相手への信頼、実際の協力、被害の減少、長期の継続は別々に測る必要がある。最初に一つが改善したことを、最終的な理想の達成と呼ばない。

<a id="s4"></a>

## 先に決めておくこと

研究として行うなら、結果を見る前に、問い、比較、主要な指標、分析の方法を明らかにする。後から都合のよい結果だけを成功と呼ばないためである。

たとえば主要な結果を、共同作業の内容を正しく説明できた割合と定める。満足度や継続意欲は別の結果として扱う。誰を対象にし、何人をどう割り当て、いつ測り、途中でやめた人をどう扱うかも決める。

人数は、気分で決めるのではなく、意味のある最小の変化、測定のばらつき、集団内の似通い方、脱落の見込みなどを踏まえて検討する。小さな試行で変化が見られなかったとしても、効果がないと断定できるとは限らない。

複数の指標を試すなら、偶然よく見える結果が出やすくなることにも注意する。結果の大きさと不確実さを示し、都合の悪い結果や、不利益も報告する。仮説を後から思いついたなら、探索的な結果として区別する。

<a id="s5"></a>

## 比較の公平さを保つ

手続を試した集団と、試さなかった集団が、最初から大きく違っていたら、結果の違いを手続の効果と断定できない。条件に応じて無作為な割当てを使うなど、別の原因を減らす設計が必要だ。

ただし、無作為に分ければすべて解けるわけでもない。隣の集団から情報が伝わる、測られていると知って行動を変える、回答したい人だけが残る、といった問題がある。研究の場に合った方法を選び、限界を記す必要がある。

職場や学校で行う場合は、上司や教師への遠慮が同意を歪めることもある。断っても不利益がないこと、個人の回答が評価へ使われないこと、情報が守られることを、実際の仕組みとして用意しなければならない。必要な倫理審査や専門的な検討を省いて、思想を試す実験を始めてはいけない。

<a id="s6"></a>

## 哲学の何が科学へ進んだのか

このように問いを分けると、共通目的という哲学の全体が科学になったのではなく、その中の手続と影響に関する部分が、検証可能になる。

「誰を大切にするべきか」という価値判断は、それだけで実験の結果にはならない。「この手続は、この条件で、理解や負担をどう変えるか」は、研究によって支持や反証を受けうる。どちらも重要だが、答え方が違う。

本書で示す研究計画は、未実施の提案である。実験を行ったとか、人々が幸せになったと報告するものではない。すでにある研究を読み、まだわからない部分を特定し、必要なら確かめる。この順序を守ることによって、理想は検討を受け入れる形になる。
