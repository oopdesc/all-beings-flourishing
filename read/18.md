# 第18章 意識を研究することと主観を考えること

<a id="s2"></a>

## 説明したいものを分ける

意識という言葉には、目が覚めている状態、情報を報告できること、自分の行動を振り返ること、何かを感じていることなど、異なる意味が入っている。議論の途中で意味を変えると、一つを説明しただけで、すべてを説明したように見えてしまう。

本書で特に気にかけるのは、何かを経験しているという側面だ。痛みを処理する機能があることと、痛みがつらく感じられることは、少なくとも問いとして区別できる。経験に関係する機能を研究することは重要だが、その研究が何を対象にしているかを明らかにする必要がある。

また、人が経験を報告するには、記憶や注意や言語などの働きが関わる。そのため、報告に伴う脳の活動が見つかっても、それが経験そのものに必要な働きなのか、報告するための働きなのかを区別しなければならない。研究設計は、このような混同を減らすために工夫される。

<a id="s3"></a>

## 競合する説明を比べる

2025年のCogitateによる研究は、統合情報理論とグローバル神経ワークスペース理論の予測を、事前に定めた方法で比較した。結果は両理論の一部の予測を支持しつつ、一部へ課題を示した。意識の謎が一つの理論で解決したという結果ではない。[[8]](30.md#ref-8)

さらに、理論側から、何が検証されたのかについての応答も出ている。[[35]](30.md#ref-35) このような論争では、研究結果そのもの、そこからの解釈、理論をどう修正するかを分けて読む必要がある。

ここに科学の進展がある。意識という大きな言葉に、もっともらしい物語を重ねるだけでなく、どの説明ならどの結果を予測するかを示し、共通の条件で比べる。支持されなかった予測があれば、それを隠さず、次の理論や実験へつなげる。

ただし、ある限られた知覚の実験が、意識のすべての側面を一度に試したわけではない。研究の対象と、結論の広さを揃えることが必要だ。

<a id="s4"></a>

## 自分を探すという問い

内省すると、「私」はどこにいるのかという問いが生まれる。感覚、記憶、思考を眺める何かがあるように感じ、その何かをさらに眺めようとする。すると、見る側と見られる側が、何度も入れ替わるように思える。

この経験から、固定した自己という考えを疑うことはできる。しかし、自分の中に一つの物として見つからないから、主体は存在しないとか、全員が同じ主体であると、直ちに結論することはできない。探し方が、その対象に合っているかという問題もある。

たとえば、会話の意味は、紙の上の一点を探しても見つからないが、それで意味が何も働いていないとは言えない。同じように、自己を物のように探す方法が、自己に関するすべての問いへ答えるとは限らない。この例は自己の正体の証明ではなく、問い方を検討するための比喩である。

内省は、自分にどのように経験が現れるかを知る重要な手がかりになる。一方、その経験が成立する仕組みや、他者の経験との同一性を決めるには、内省以外の情報も必要になる。

<a id="s5"></a>

## 物理の言葉で飛躍しない

脳も身体も物理的な世界に属するから、物理学の理解は意識研究と無関係ではない。しかし、「量子」「情報」「共鳴」「創発」といった言葉を添えるだけでは、経験がどう生じるかを説明したことにならない。

創発という言葉を使うなら、どの構成要素から、どの条件で、何が現れるのかを示す必要がある。情報量を増やすと能力が変わるとしても、能力の変化がそのまま意識経験の発生を意味するわけではない。

また、物理学の観測や測定に関する議論を、人間の願いが自由に現実をつくるという主張へ置き換えてはいけない。測定装置との相互作用についての説明と、主観的な願望についての説明は別のものだ。

<a id="s6"></a>

## 謎を残したまま進める

意識の完全な説明がまだなくても、できる研究はある。経験の報告と身体の状態の関係を調べる。理論の予測を比べる。人間以外の経験を推測する根拠を増やす。人工システムに指標を当てはめる際の前提を検討する。

同時に、哲学には、説明によって何を知りたいのか、何を同じ経験と呼ぶのか、主観を第三者の記述へどこまで置き換えられるかを考える役割がある。科学と哲学は、互いの不足を理由に相手を無価値にする必要はない。

私たちは、最終的な意識理論を持たなくても、苦しみを訴える人へ配慮できる。理論が完成するまで、当事者の生活を保留にする必要はない。未知を探る知性と、既知の切実さに応じる倫理を、同時に持ちたい。
