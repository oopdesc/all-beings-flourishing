# 第4章 目的が衝突するとき

<a id="s2"></a>

## すべての願いは同時に叶うか

ある広場を、夜も音楽を楽しめる場所にしたい人がいる。同じ広場の近くで、静かに眠りたい人がいる。この二人を前にして、「みんなの目的を叶えよう」と言うだけでは、何も決まらない。

ここで三つのことを分けてみる。二人が表明した具体的な要求、要求の背後にある利益、その利益を守るための手段である。深夜に演奏するという要求の背後には、音楽や交流の機会があるかもしれない。音をなくすという要求の背後には、休息や健康があるかもしれない。

時間帯を変える、防音した別の場所を設ける、催しの回数を調整する。手段を広げれば、最初の二択にはなかった案が生まれる。このような問題では、相手の目的を消すより、目的を理解して手段を増やす方がよい。

しかし、すべての衝突がそう解けるわけではない。同じ時刻、同じ場所、同じ条件で、音があることとないことを、同時に実現することはできない。衝突を認めることは理想への敗北ではない。解決すべき場所を正確にすることだ。

<a id="s3"></a>

## 目的を問い直すことと人を否定すること

目的は、最初から完成した形で心の中に入っているとは限らない。知識や経験が変われば、自分の望みも変わる。必要だと思っていたものが、別の形でも満たされると気づくことがある。

だから、相手の目的について質問すること自体は、相手の自由の否定ではない。「何があれば困らずに済むのか」「どの部分は変えられないのか」「別の案なら受け入れられるか」と尋ねることはできる。質問される側にも、答えない自由と、違うと訂正する機会が必要だ。

一方、「本当の幸福はこれだ」と外から決め、本人の言葉をすべて未熟な考えとして処理するなら、目的の検討は支配になる。特に、資源や立場を持つ側が、弱い立場の人にだけ我慢を求めるときには注意が要る。

また、長く不利な環境に置かれた人が、「自分にはこれで十分だ」と言った場合も、その言葉を無視せず、選択肢が本当にあるかを確かめたい。満足しているという報告だけでも、外から見た基準だけでも、その人の生活を十分には理解できない。

<a id="s4"></a>

## 他者を害する目的をどう扱うか

相手を苦しめること自体を望む人と、苦しめられたくない人がいるなら、二つの要求はそのままでは両立しない。「双方の目的を等しく実現する」と言うだけでは、被害を正当化してしまう。

本書では、存在への配慮と、要求への承認を分ける。誰かを苦しめるという要求は制限する。それでも、要求した人を、人間ではないものとして扱ったり、苦しめ返したりする必要はない。安全を確保しながら、行為の背景や、別の関わり方を検討できる。

この立場は、宇宙のすべての存在がすでに同意している倫理ではない。深刻な加害を避け、自律を守るという、本書の価値前提に基づく。異なる価値を持つ相手に、それが必ず通じるという保証はない。だからこそ、対話だけでなく、法、保護、権力の制限、被害への対応が必要になる。

協力を目指すことは、危険な場から離れる自由を失うことではない。相手を憎まないことと、相手の近くに居続けることも同じではない。共通目的という言葉が、被害を受ける人を閉じ込める理由になってはならない。

<a id="s5"></a>

## 残る損失を正直に扱う

代替案を探し尽くしても、時間や資源の不足から、全員の希望を満たせないことはある。そのときは、損失がなかったことにせず、誰が何を失うかを示す必要がある。

まず、深刻で回復しにくい被害を避ける。次に、影響を受ける人が説明と異議申立ての機会を持てるようにする。比較できない価値が残るなら、その比較が政治的・倫理的な判断であることを認める。可能であれば、負担の分担、補償、交代、期限つきの試行を考える。

この順序も、すべての場面を自動で解く機械ではない。自由どうしが衝突することも、保護のための制限が必要なこともある。必要なのは、誰か一人が「全体のため」と言えば終わる仕組みを避け、理由と影響を確かめ続けることである。

「すべての存在が幸せになる」という理想は、衝突が存在しないと信じることではない。衝突の中でも、相手を最初から捨てる対象にしないことだ。達成したと宣言するための旗ではなく、まだ配慮が届いていない場所を探すための問いとして使いたい。
