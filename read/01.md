# 第1章 苦しみを配慮の出発点にする

<a id="s2"></a>

## 誰かの内側で起きていること

この本の出発点は、望まない苦しみを、誰にも味わわせたくないという思いだ。苦しみを経験した人だけが倫理を語れるという意味ではない。自分が経験していなくても、他者の言葉に耳を傾け、その生活を想像し、助ける方法を学べる。ただ、苦しんでいる本人の経験を、外から簡単に取り消してはいけないと思う。

痛みのある人の隣に立っても、私たちにはその痛みが直接流れ込んでこない。そのため、見た目が変わらない、仕事に来られている、説明がうまくできないという理由で、被害が小さく見えることがある。しかし、外からわからないことは、存在しないことではない。

ここから言えるのは、他者の訴えを必ず無条件で事実認定せよ、ということではない。出来事の原因や責任を判断するには調査が必要だ。それでも、苦しみの訴えを受け止めることと、原因を慎重に確かめることは両立する。話を聴く段階と、すべての説明を正しいと認める段階を分ければよい。

たとえば、ある人が「職場がつらい」と話したとする。本人が弱いと決めつけるのも、周囲の全員が悪意を持っていると即断するのも早い。仕事量、休息、役割、対人関係、健康状態を分けて確認できる。その間も、休憩や相談の機会を用意することはできる。原因の完全な解明を、配慮の開始条件にしないのである。

<a id="s3"></a>

## 私の経験から他者の経験へ

私が自分の苦しみを避けたいと思うのは、それが私のものだからだけなのだろうか。それとも、苦しみとしてつらいものだからなのだろうか。後者にも理由があるなら、他人の苦しみも考慮に入れる理由がある。

ここには一つの橋が架かっている。まず、自分の経験には、自分にとって切実な価値がある。次に、他者もまた、その人にとって切実な経験を持つと考える十分な理由がある。さらに、当事者の名前が変わるだけで、その切実さを無価値にしてよいとは考えない。この最後の部分は、観測結果ではなく、公平さについての私の選択である。

この選択に同意しない人を、論理だけで必ず説得できるとは限らない。自分以外はどうなってもよいという立場には、誤った計算を一つ直せば済むという種類の反論はできないからだ。それでも、その人自身が被害を受ける側になったとき、同じルールを受け入れられるのかと問うことはできる。役割を入れ替えて考えることは、選択の一貫性を確かめる方法になる。

これは、全員の痛みが同じ量だという主張ではない。個人差も、状況の違いもある。等しく配慮するとは、全員に同じ対応をすることではなく、違いがあるなら、その違いに即した理由で対応を変えることだ。

<a id="s4"></a>

## 苦しみを減らすことと生を消すこと

苦しみがないことだけを最優先にすると、危うい結論が出る。経験する主体がいなければ苦しみもないのだから、存在そのものをなくせばよい、という結論である。本書はその結論を採らない。

なぜなら、本書が大切にするのは苦痛の少なさだけではないからだ。生きること、関係を続けること、自分の生を選ぶこと、喜びや意味を経験できることも大切にする。苦しみを理由に、本人の望む生を奪うのは、この複数の価値を一つに押しつぶす判断になる。

また、本人が望む挑戦に含まれる負担と、望まない深刻な被害も区別する必要がある。楽器の練習で疲れることと、休む自由もなく追い込まれることは同じではない。挑戦を選べること、途中でやめられること、負担について十分に知っていることが、両者を分ける。

苦しんだ経験から何かを学ぶ人はいる。しかし、そこから「成長には苦しみを与える必要がある」とは導けない。すでに起きた経験から意味を見いだすことと、意味のために他者へ被害を与えることは別だからだ。苦しみを経験した人に、必ず成長の物語を語らせる必要もない。

<a id="s5"></a>

## 大きな理想より先にできること

すべての苦しみを一度に解決できないとき、何もしないか、全身全霊で世界を救うかの二択にする必要はない。現実には、その間に多くの行動がある。説明をわかりやすくする、助けを求められる窓口をつくる、無理な期限を見直す、孤立した人の話を聴く。小さく見える変更でも、当事者の一日には大きな違いを生むかもしれない。

その変更が役に立ったかどうかは、善意の強さでは判断できない。「助けたつもり」が、本人の負担を増やすこともある。したがって、できる限り本人の希望を確かめ、試した後に影響を聴き、不要ならやめる。この手順が、理想と日常をつなぐ。

自分の生活を維持することも、この手順の内側にある。全員の幸福を考えるというなら、自分だけを計算から外す理由はない。休息を取ること、支援を受けること、いまは関われないと伝えることは、思想への裏切りではない。

この章の結論は、他者の経験を、自分から遠いという理由だけで軽く扱わないことだ。ここから、誰の経験まで配慮に入れるべきかという問いが生まれる。その問いに進む前に、次章では、事実と価値と推論を分ける。
