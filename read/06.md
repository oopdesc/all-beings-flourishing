# 第6章 自分と他者の境界を考える

<a id="s2"></a>

## 自分の経験だけが近く見える

自分の空腹や不安は、説明されなくてもわかる。他者の空腹や不安は、表情や言葉や行動から知る。この違いのために、自分の利益は切実で、他者の利益は抽象的に見えやすい。

しかし、私にとって遠いということは、その人にとっても遠いということではない。その人の苦しみは、その人の経験の中心にある。私が相手を背景のように扱っても、相手の内側の世界が背景になるわけではない。

ここに、自他の境界を問い直す意味がある。自分の視点が世界のすべてではないと知ることは、自分を無価値にすることではない。自分と同じく、それぞれの視点があると認めることである。

私が望むのは、自分と他者の差をすべて消すことではない。違いがあることを認めながら、近さだけを理由に、価値を極端に変えないことだ。家族や友人を特に気にかける関係はありうる。それでも、遠くの人の苦しみを、最初からゼロとして扱う必要はない。

<a id="s3"></a>

## すべての主観は一つなのか

私の思索の中には、一つの想像がある。私たちが「自分」と呼ぶ経験の主体は、根底では同じものであり、それぞれの生の中で異なる経験をしているのではないか、という想像だ。

これは現在の科学が確認した事実ではない。

似た問題意識は、Kolakの著書で論じられる開かれた個人性にも見られる。[[34]](30.md#ref-34) 本書の想像を、先例のない発見として扱うことはできないし、その先行する哲学があることも、科学的な証明の代わりにはならない。異なる人の脳や行動に共通性があることと、経験している主体が数的に同一であることは違う。似た構造の機械が二台あっても、それだけで同じ一台とは呼ばないのと同じく、共通性から同一性へ進むには、別の議論が必要になる。

さらに、すべての主体が一つだという説と、主体はそれぞれ別だという説が、観測される結果について何も違う予測をしないなら、いまの観測によって両者を選ぶことはできない。意味のある哲学的な問いでありえても、実験で支持された理論とは呼べない。

この区別をしたうえで、この想像には倫理的な働きがありうる。もし自分が相手の位置から世界を経験していたら、どう扱ってほしいだろう。そう問うための視点として使える。ただし、想像が役立つことは、その宇宙論的な正しさの証明ではない。

<a id="s4"></a>

## 同一でなくても配慮できる

他者を大切にするために、他者が実は自分であると証明する必要はあるのだろうか。私は、必要ないと考える。

仮に主観が別々なら、他者には、自分が代わりに経験できない固有の生がある。それは、尊重する理由になる。仮に根底に共通する何かがあるとしても、現実に異なる身体、記憶、望み、関係があることは変わらない。それらを乱暴に扱ってよい理由にはならない。

第1章で述べた公平さと配慮を採るなら、どちらの仮説でも、相手の訴えを聴き、同意を確かめ、被害を避けるという行動を支持できる。このように、答えがまだない形而上学の問いに、日常の配慮を全面的に依存させない方がよい。

「あなたも私なのだから、私の望むことに従ってよいはずだ」という言い方は、本書の立場に反する。相手を自分の延長とみなして支配するなら、自他の境界を問い直す思想が、かえって他者を消してしまうからだ。

<a id="s5"></a>

## 無我から何を学ぶか

仏教には、固定した独立の自己を問い直す考えや、苦しみとその軽減を重視する倫理の伝統がある。ただし、教えは一様ではなく、無我という言葉を、そのまま「全員が一つの意識である」と置き換えることはできない。[[19]](30.md#ref-19)

ここで私が学びたいのは、私というものを、変化しない所有者のように固めすぎない態度だ。身体、記憶、言葉、周囲の人との関係によって、私はいまの私になっている。自分を保つことと、変化を認めることは、対立しなくてもよい。

また、執着を緩めることと、被害を受けても何も言わないことは違う。自分へのこだわりを問い直す思想が、他者によって服従を求める道具として使われるなら、その使い方も問い直さなければならない。

自分を少し遠くから眺め、他者を少し近くから考える。その往復の中で、私たちは、主観の最終理論を持たないままでも、関わり方を変えられる。境界についての謙虚さは、境界を侵害する許可ではない。
