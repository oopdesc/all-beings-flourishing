# 第15章 協力を小さなモデルで確かめる

<a id="s2"></a>

## 数字を置く理由と限界

ここからは、哲学の一部を、前提が見える形へ落とす。新しい社会法則を発見したと主張するのではない。協力研究で扱われてきた公共財型の構造を、小さな架空の例で説明する。[[43]](30.md#ref-43)

以下の数字は、実際の人の幸福を測った値ではない。現実の実験の再現データでもない。計算の中で何が起こるかを追うための、仮定上の点数である。前提が変われば結果も変わる。

三人が共同の活動を行うとする。各人は、資源を1単位出すか、出さないかを選ぶ。集まった資源は二倍の価値になり、三人へ等しく配られる。自分の取り分から、自分が出した資源を引いたものを、ここでの利得と呼ぶ。

<a id="s3"></a>

## 全員で出す方がよいのに出さなくなる

全員が1ずつ出すと、合計3が二倍になって6となり、一人へ2ずつ配られる。自分の拠出1を引くと、全員の利得は1である。

全員が何も出さなければ、配られるものもなく、全員の利得は0である。二つの結果を比べると、全員が出す方が、全員にとってよい。

ところが、自分一人の選択を見ると事情が変わる。自分が1を出すことで増える自分の取り分は、二倍にした2を三人で分けた、3分の2だけである。支出は1なので、自分の利得は3分の1減る。

したがって、ほかの二人の選択が同じなら、自分は出さない方が、いつも3分の1だけ利得が大きい。この利得だけを最大にする三人が同時に考えると、全員が出さないという結果へ向かう。全員にとってよい結果が、各人の個別の利得最大化からは出てこない。

<a id="s4"></a>

## この例から言えること

このモデルが示すのは、計算能力を上げるだけでは、協力が生まれるとは限らないということだ。むしろ、個別の利得だけを正確に計算すると、協力しない選択が導かれる。この例では、問題は計算の誤りではなく、利益の構造にある。

変えられる条件もある。将来の関係を考慮する、貢献が確実に報われるようにする、全員が合意した条件で共同の活動を成立させる。どの条件が有効かは、それぞれに検討が必要だ。

「情報を増やせば解ける」という主張にも注意が要る。このモデルでは、三人が仕組みを完全に知っていても、個別の利得の構造は変わらない。他者の行動への誤解を減らすことが重要な現実の場面と、情報だけでは解けない利害の問題を区別したい。

<a id="s5"></a>

## この例から言えないこと

現実の人は、ここで定めた利得だけで行動するわけではない。公平さ、他者への思い、信頼、規範などを重視する人もいる。第8章で紹介した2026年の国際実験は、特定の条件で多くの人が協力を選ぶことを報告している。[[37]](30.md#ref-37)

また、この架空の三人のモデルと、その国際実験は同じ設計ではない。モデルの結果を使って、実験結果が間違いだと言うことも、実験結果を使ってモデル内の計算が間違いだと言うこともできない。前提と対象が違うからである。

この違いが、モデルと現実をつなぐ研究の出発点になる。現実の選択は何に左右されるのか。制度を変えると、どの行動が変わるのか。理論から予測を立て、観察から前提を修正する。その往復を省いて、数式だけで社会が説明できたとは言わない。
