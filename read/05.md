# 第5章 幸福を測ると何が見えるか

<a id="s2"></a>

## 幸福という一語をほどく

楽しい時間を過ごすこと、人生に満足すること、苦しい中でも大切な仕事に意味を感じることは、重なりながらも異なる経験だ。幸福を一つの数字にまとめる前に、その違いを見ておきたい。

OECDの2025年版の測定指針は、主観的な幸福を、生活への評価、感情、意味や充実に関わる側面に分けて扱う。測定対象を分けることによって、同じ「よくなった」という言葉の中身を確かめられる。[[1]](30.md#ref-1)

2025年に初期結果が報告されたGlobal Flourishing Studyは、22か国の大規模な調査で、幸福だけでなく、健康、意味、人間関係などを扱っている。[[24]](30.md#ref-24) 2026年8月の追加分析も、主観的な評価と客観的な生活条件を複数の側面から比較した。[[38]](30.md#ref-38) ただし、観察された関連だけから、ある生き方や制度が幸福を生んだと断定することはできない。

たとえば、試験前の学生は、疲れや不安を感じながらも、学ぶことに意味を見いだしているかもしれない。別の人は、日々は穏やかでも、将来を選べる感覚を失っているかもしれない。この二人を、一つの得点だけで並べると、大切な違いが落ちる。

本書では、快い感情だけでも、目的の達成だけでも、幸福全体を定義しない。本人の経験、生活条件、選択の自由、関係、将来への見通しを、関連する複数の側面として考える。どれをどれだけ重く見るかは、測定技術だけでは決まらない。

<a id="s3"></a>

## 幸福を定義するのは誰か

測定には、事実を記録する仕事と、何をよい生とみなすかを選ぶ仕事が入っている。「健康」「意味」「徳」と項目を並べても、それぞれを何と理解するかは一通りではない。

Willenらは、幸福研究で用いられる概念や指標に、特定の宗教的・規範的な前提が入り込む問題を批判している。[[45]](30.md#ref-45) 2026年の国際比較の著者たち自身も、新たに構成した客観的指標の妥当性、文化的な偏り、国の平均が内部の違いを隠すことを、限界として挙げている。[[38]](30.md#ref-38)

こうした批判を受けて、調査を捨てる必要はないと思う。むしろ、測定の前提を見えるところへ置きたい。ある尺度が安定して回答を得られることと、その尺度の価値観へ全員が従うべきことは別である。研究者の信仰の有無だけで結果の正否を決めるのでもない。問うべきなのは、定義とデータと解釈のつながりである。

たとえば、孤独を好む人の静かな生活を、交際の頻度だけで劣った生と採点すれば、測定が本人の大切にするものを傷つける。比較のための共通項目を使いながら、本人の説明と異議を残す。その両方を保つことが、幸福を共通の課題にするときの最低限の配慮だと考える。

<a id="s4"></a>

## 本人の答えを尊重しながら確かめる

「いまの生活にどのくらい満足していますか」と尋ねることには価値がある。外部の評価者には見えない経験を、本人の言葉で表せるからだ。しかし、回答は質問の仕方、直前の出来事、比較する相手、答えやすさにも左右されうる。

そのため、一度の点数を、その人の幸福の全体像だと決めつけない方がよい。同じ人の変化を見る場合でも、測る時期や方法を揃え、生活に何が起きたかを一緒に聴く必要がある。

また、平均点が上がったとき、その変化が誰に起きたかを調べたい。九人の小さな改善と、一人の深刻な悪化が、平均の中で相殺される場合がある。全員の幸福を考えるというなら、分布と、特に不利な立場の人の変化を確認しなければならない。

逆に、ある一人の回答だけで、制度全体の効果を決めるのも早い。本人の訴えは重要な情報として受け止め、ほかの情報と照らし合わせる。統計と個人の声は、どちらか一方を捨てるためにあるのではない。

<a id="s5"></a>

## 目的を選べる条件

幸福を高めるために、本人の選択をすべて外から管理すればよいのだろうか。たとえ気分がよくなるとしても、何を学び、誰と関わり、どこで暮らすかを他者に決められる生活には、失われるものがある。

自己決定理論を整理したRyanとDeciの論文は、自律性、有能感、関係性が動機づけや良好な機能に関わると論じている。これは、自由さだけであらゆる困難が解けるという主張ではなく、本人を支える環境の重要性を示す理論と研究の整理である。[[2]](30.md#ref-2)

私がここから重視するのは、「よい結果を与える」だけでなく、「本人が関われる条件をつくる」という方向だ。説明を理解できること、別の選択肢を知れること、断ったことで不当に罰せられないこと。支援の中に、このような条件を組み込む。

子どもや、意思を伝えることが難しい人についても、周囲の都合だけで決めない。表現を助ける方法を探し、本人の利益を推測する際には、その推測の限界を記録する。自律を尊重するとは、支援なしで選べと放置することではない。

<a id="s6"></a>

## 測定が目的を置き換えるとき

ある施設で、利用者の満足度を上げる目標を設定したとする。職員が本当に生活を改善すれば、測定は役に立つ。しかし、低い点をつけそうな人を調査から外したり、よい点をつけるよう求めたりしても、数字だけは上がる。

このとき改善されたのは、幸福ではなく、その代理として使っていた指標である。指標が報酬や評価に強く結びつくほど、何が数字の外へ落ちているかを確認する必要がある。

だから、測定を行うなら、目的、対象、質問、集計方法を先に明らかにし、不利益や異議も記録する。個人をランキングして支配する道具にしない。回答しない自由や、情報を守る方法も設ける。

測れない価値を無価値とみなさず、測れるものを使わない理由にも逃げない。数字は、配慮を助ける情報として使う。この位置づけを守るなら、哲学の問いの一部を、実際に確かめられる問いへ進められる。
