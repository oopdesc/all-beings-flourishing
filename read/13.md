# 第13章 神のゲームという比喩と自律

<a id="s2"></a>

## 命令に見えるものを問い直す

私は、従わなければ大変なことが起こると感じ、自分の判断を手放してしまう状態を考えるために、「神のゲーム」という比喩を使ってきた。ここで神という語は、実在が確認された命令者を指すのではない。疑うことのできない権威のように感じられるものを表している。

それは外部の人や組織かもしれないし、自分の中の強い確信や不安かもしれない。何かが特別な意味を持つように感じられ、その意味を確かめるために、さらに行動を求められる。いくら応じても、次の条件が生まれ、終わりが見えなくなる。

このような経験があることと、その内容を告げる超自然的な存在がいることは別である。切迫した感じや、偶然の一致や、繰り返し思い浮かぶ言葉だけでは、外部の命令の正しさは確認できない。

本章は、読者の経験を一つの病名に当てはめるために書くものではない。思想上の比喩と、心身の健康に関わる問題を区別しながら、自分の判断を守るための考え方を示す。

<a id="s3"></a>

## 権威の強さと理由の強さ

ある命令が、神、国家、組織、専門家、AIなどの名前を伴っていても、その行為が必要で安全であることの証明にはならない。誰が言ったかは情報の一つだが、何を求め、どんな根拠があり、誰に何が起きるかを確かめる必要がある。

「疑うこと自体が悪い」「今すぐ行動しなければならない」「他の人には相談してはいけない」と言われるとき、検討の通路が閉じられている。この閉じ方を、真理の強さと取り違えない方がよい。

自分の中に生じる考えについても同じことが言える。強く感じることは、その考えが自分にとって切実であることを示すかもしれない。しかし、現実の危険を正確に予測しているとは限らない。感情は大切な経験であり、同時に、外界の事実とは別に確認されるべき情報でもある。

<a id="s4"></a>

## 超えるとは支配し返すことではない

私がこの比喩から取り出したい答えは、命令者より強くなって支配し返すことではない。自分の価値と、他者の生を守る理由に基づいて、従うかどうかを考え直せるようになることだ。

よりよい仕組みをつくれる可能性はある。人を従わせる仕組みの代わりに、対話できる仕組みをつくれるかもしれない。しかし、現実の何でも同じものを再現できるとか、必ずそれ以上のものをつくれるとは保証できない。失われた個人や関係を、別のものができるという理由で軽く扱ってはいけない。

だから、自律の根拠を、無限の力や、必ず勝てるという確信に置かない。限界があっても、理由を尋ね、断り、助けを借りる権利がある。相手より強いことを証明しなくても、危険な要求に従う義務は生じない。

<a id="s5"></a>

## 考え続けることだけを解決にしない

不安を完全に論破できるまで、何時間も考え続けなければならないと感じることがある。しかし、確認や議論を重ねる行為自体が、負担を増やす場合もある。

NHSは、望まない考えと、それによる不安を一時的に和らげるための反復行為を、強迫症についての説明で区別し、生活に影響する場合の相談を案内している。[[17]](30.md#ref-17) また、声を聞く経験にはさまざまな原因があり、医療的な評価が必要な場合がある。[[18]](30.md#ref-18) これらの情報から、個々の読者の状態を本だけで診断することはできない。

本書が勧めるのは、哲学だけで必ず解決しようとしないことだ。考えや声が行動を強く迫り、生活や安全を損ねるなら、信頼できる人や医療の専門家に、起きている経験を具体的に伝えてよい。治療を受けることと、自分で考えることは対立しない。

とくに、自分や他者を傷つける行動を迫られているときは、その内容を哲学的に確かめるために実行してはいけない。安全な場所へ移り、一人で抱えず、地域の救急や医療につながることを優先する。確信の意味を決着させる前に、安全を守ることができる。

<a id="s6"></a>

## 自律は一人きりになることではない

誰にも従わないことを、自律の唯一の姿にすると、他者の助言や専門知識まで拒んでしまう。自律とは、何も借りないことではない。説明を受け、考え、必要に応じて委ね、違うと思えば相談し直せることである。

感情を持たずに論理だけで生きる必要もない。喜びや不安や怒りは、自分に何が大切かを知る手がかりになる。ただ、それらを、検討できない命令として固定しない。感情、理由、現実の情報、他者の支えを行き来しながら判断する。

神のゲームという比喩の出口は、特別な存在へ昇格することではない。今日の自分の安全と、他者への配慮を保ちながら、一つの選択を取り戻すことにある。その選択を支えられる社会をつくることも、共通目的の一部である。
