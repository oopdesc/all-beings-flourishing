# How Much Can We Know About the Universe?

First English edition · October 27, 2026

Starting with light that reaches us from distant space, this book asks what we can know about the universe, time, and consciousness. It follows the steps between observation, model-dependent inference, mathematics under stated assumptions, and questions that remain open.

Includes the conclusions, 17 chapters, mathematical notes A–I, 63 references, and a colophon. The bibliography states the scope consulted for each source.
