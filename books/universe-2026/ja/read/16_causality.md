# 第16章 原因を知ることと、予測を信じられること

何が起きるかを当てることと、何を変えれば結果が変わるかを知ることは、似ていますが別の仕事です。晴れの日に人が多く外へ出るとわかっても、人を外へ出せば晴れるとは言えません。宇宙の説明でも、社会をよくする試みでも、この違いは重要になります。

科学の範囲を広げるとは、何でもすぐ科学と呼ぶことではないでしょう。予測や原因についての問いを細かくし、どの条件なら答えられるかを増やしていくことです。

<a id="h-2"></a>

## 変えた場合と、変えなかった場合

ある学習法を使った人の成績が高かったとします。その差は、学習法の効果でしょうか。もともと意欲の高い人がその方法を選んだのかもしれません。課題の難しさや、使える時間も違うかもしれません。

因果効果を考えるときには、同じ対象について、その学習法を使った場合の結果Y(1)と、使わなかった場合の結果Y(0)を区別します。その差を知りたいのですが、同じ一回について両方を観測することはできません。そこで、別の対象を比べるために、どんな仮定や研究設計が要るかを考えます。<a id="cite-56"></a>[[56]](19_references.md#ref-56)

無作為な割り付けは、そのための強い方法です。割り付けが適切に行われれば、介入前の性質による偏りを、割り付けの仕組みとして抑えられます。ただし、実際の一回ですべての性質が完全に揃うわけではありません。途中でやめた人、指示どおり使わなかった人、測定できなかった結果をどう扱うかも残ります。

<a id="h-3"></a>

## 合計すると、向きが逆になる

以下は、実在する学習法の評価ではなく、集計の意味を確かめるための架空の数字です。「使う群」と「使わない群」が、簡単な課題と難しい課題へ偏って分かれていたとします。

| 課題 | 使う群の成功 | 使わない群の成功 |
| --- | --- | --- |
| 簡単 | 8/10人、80% | 63/90人、70% |
| 難しい | 18/90人、20% | 1/10人、10% |
| 合計 | 26/100人、26% | 64/100人、64% |

簡単な課題でも難しい課題でも、使う群の成功割合は10ポイント高くなっています。ところが、合計では使う群のほうが38ポイント低くなりました。使う群には、難しい課題の人が多いからです。

比較する両方の群に、簡単と難しい課題を半分ずつ置くとどうでしょうか。使う群は、80%と20%の平均で50%。使わない群は、70%と10%の平均で40%です。課題の構成を揃えると、差は10ポイントになります。

これは、数字の矛盾ではありません。合計の割合は、各課題での割合だけでなく、各課題へどれだけの人数を配ったかにも依存するからです。どんな集団について知りたいのかを定めずに、最も見栄えのよい集計を選ぶことはできません。

ただし、この表を調整しただけで、学習法の因果効果が証明されたわけでもありません。課題の難しさ以外に、比較をゆがめる条件が残っているかもしれないからです。

<a id="h-4"></a>

## 観測から原因へ進むための条件

観測データから介入の効果を推定するには、対象とする介入が明確で、観測した結果と対応する必要があります。これを一致性という条件として扱います。また、調整に使った条件の下で介入の選択と潜在的な結果を比べられること、さらに必要な条件の層で両方の介入を受ける可能性があることなどが要ります。後者は正値性と呼ばれます。[[56]](19_references.md#ref-56)

難しい語が並びますが、問いは具体的です。何をしたことを「使った」と数えるのか。比べる相手は、観測されない性質まで含めて違いすぎないか。ある条件の人が片方の方法を一人も使っていなければ、その条件での比較をどこから得るのか。

これらは、データを大量に集めれば自動で満たされる条件ではありません。また、介入した後の変数を何でも調整すればよいわけでもありません。どの経路の効果を知りたいかを変えたり、かえって偏りを入れたりする場合があります。対象の知識と因果の構造を、統計の前に考える必要があります。

他の人への介入が自分の結果にも影響する場合には、自分が使ったかだけのY(1)、Y(0)では問いを十分に表せません。誰への、どんな割り付けを比較するかから定め直します。単純な数式を使える範囲を知ることも、より広い現象へ進む準備になります。

2026年の外部対照試験に関するレビューも、まず知りたい因果量を定め、識別の仮定を置き、その後に推定と不確実さの評価へ進む枠組みを整理しています。<a id="cite-57"></a>[[57]](19_references.md#ref-57) 高性能な計算が、問いと仮定を肩代わりするわけではないのです。

<a id="h-5"></a>

## 当たる予測にも、幅を持たせる

原因とは別に、予測の信頼性そのものを改善する数学も進んでいます。たとえば、物理現象の数値計算を、機械学習による近似模型で速く予測することがあります。そのとき、一つの数字だけでなく、どれくらい外れる可能性を残すかを知りたくなります。

適合的予測、英語でconformal predictionと呼ばれる方法は、予測模型とは別に用意した校正データなどを使い、誤差の順位から予測区間を作ります。適切な交換可能性の条件の下で、新しい結果を区間に含める割合について保証を与えます。交換可能とは、考える標本の順序を入れ替えても、その結合分布が変わらないことです。<a id="cite-51"></a>[[51]](19_references.md#ref-51)

一番小さな例を見ましょう。予測模型を先に固定し、九つの校正例について絶対誤差を測ります。その最大値を幅にします。校正例と新しい一例を合わせた十個の誤差が交換可能で、同点がなければ、新しい一例の順位は十通りに均等です。

新しい誤差が九個の最大値を超えるのは、十個全体の最大になった場合だけ。したがって、この仕組みを繰り返す分布全体での被覆率は90%です。[数理ノートE](18_math_notes.md#note-e)に前提を含めてまとめました。九例でいつも実用的な狭い区間が得られる、という意味ではありません。

<a id="h-6"></a>

## 保証の主語を確かめる

2026年のGopakumarらの研究は、物理の近似模型へこの方法を適用しています。ただし、その保証は時空の各セルについての周辺被覆であり、特定の入力条件ごと、あるいは場全体のすべての点を同時に覆う保証ではありません。校正と予測の間の交換可能性にも依存します。[[51]](19_references.md#ref-51)

この違いは大切です。「全体として90%」なら、特定の難しい条件では、もっと頻繁に外れるかもしれません。また、時系列を同じ長さに区切っただけで、分布が同じになったことが証明されるわけではありません。季節、装置、運用条件が変われば、前提と実際の被覆を確かめ直す必要があります。

学習時と違う分布でも使えたという結果も、校正と予測の分布が自由に違ってよいという意味ではありません。どことどこの間に同じ条件を求めているのかを読めば、方法の強みを過大にも過小にもせずに使えます。

<a id="h-7"></a>

## 科学にできる範囲は、こうして広がる

原因についての問いには、介入と比較の条件を置きました。予測についての問いには、誤差を測り、保証の対象を定めました。この二つだけで宇宙の本質が解けるわけではありません。それでも、漠然とした期待の中から、他の人も確かめられる部分を取り出せます。

数学は、仮定の下でどんな保証が出るかを示します。科学は、その仮定と測定が現実でどこまで成り立つかを調べます。哲学は、何を知りたいのか、何を原因や説明と呼ぶかを問い直します。その往復によって、わかることを少しずつ増やせます。
