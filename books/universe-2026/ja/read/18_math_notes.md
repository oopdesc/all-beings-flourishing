# 数理ノート 前提から結論までをたどる

本文の計算を、途中を確かめられる形でまとめます。いずれも本書のために設定した例です。既存研究の原データを再解析した結果や、新しい数学の定理として提示するものではありません。手計算の導出に加え、有限の例と数値を短いプログラムで照合しました。形式証明支援系による検証は行っていません。

式を読み慣れていない場合は、各節の「ここでわかること」から先に読めます。本文へ戻るリンクも付けました。

## A 同じ観測を通る、違う説明

**ここでわかること：有限個の観測点に合うだけでは、その先の予測が一つに決まるとは限りません。**

二つの関数を、f(x) = x、g(x) = x + x(x−1)(x−2)とします。

xが0、1、2なら、追加した積のどれか一つが0になります。そのため、この三点ではfとgの値は同じです。ところが、xが3では、

f(3) = 3

g(3) = 3 + 3×2×1 = 9

です。したがって、三点で一致したことから、すべてのxで一致するとは導けません。追加の観測や、許す関数についての条件が要ります。

これは、実際の物理理論がどれも同じ価値だという証明ではありません。物理では、他の観測との整合、対称性、独立した予測、使う範囲なども比較します。この例は、観測点への適合だけで論証を終えないための反例です。

## B 条件の向きを逆にしない

**ここでわかること：感度が99%でも、判定されたものの99%が本物になるとは限りません。**

第12章の架空の判定器で、Hを本物、Dを信号だという判定とします。

P(H) = 0.001

P(D｜H) = 0.99

P(D｜Hでない) = 0.01

同時に本物であり、信号と判定される確率は、0.001×0.99 = 0.00099です。本物でなく、信号と判定される確率は、0.999×0.01 = 0.00999です。二つは重ならない場合なので、Dの確率は合計0.01098になります。

よって、P(H｜D) = 0.00099/0.01098 = 11/122 ≈ 0.09016です。

母集団の頻度が変われば答えも変わります。ここには、実在の検出器や病気についての推定は含まれません。

## C 適合とベイズ因子を分ける

**ここでわかること：最良の適合が同じでも、事前に許した範囲によってモデル全体の比較は変わります。**

観測値xが、平均μ、標準偏差1の正規分布に従う模型を考えます。結果をx = 3とします。標準正規密度をφ、累積分布をΦと書きます。

H0ではμ = 0なので、観測値の密度はφ(3)です。

H1では、μが−aからaの一様事前分布に従うとします。aは3より大きく、観測の前に決めます。最良の平均はμ = 3ですから、最大尤度の比は、

φ(0)/φ(3) = exp(9/2) ≈ 90.017

です。一方、H1での周辺尤度は、μについて密度を平均したものです。

m1(3) = {Φ(a−3) − Φ(−a−3)}/(2a)

H1をH0へ比べるベイズ因子は、B10 = m1(3)/φ(3)となります。

| a | 最大尤度の比 | ベイズ因子B10 |
| --- | --- | --- |
| 5 | 約90.017 | 約22.051 |
| 50 | 約90.017 | 約2.256 |
| 500 | 約90.017 | 約0.226 |

H1が許す範囲のうち、観測と合いにくい場所にも重みが配られるため、平均は変わります。H1とH0自体への事前の確率も置けば、それとベイズ因子からモデルの事後オッズを求めます。ベイズ因子そのものを、H1が正しい確率とは呼びません。

これは、現実の宇宙論の数字を再現した計算ではありません。第4章で異なる比較尺度を読むための、仕組みだけを取り出した例です。

## D 逐次的に見てもよい条件

**ここでわかること：条件を満たす非負の記録なら、途中で止めることを含めて、大きな値が出る確率を抑えられます。**

各時点で、過去を条件としても、表と裏がそれぞれ確率1/2であると仮定します。表をX = 1、裏をX = 0とします。結果を知る前に選んだ数λを−1から1の範囲に置き、一回の係数を、

B = 1 + λ(2X−1)

とします。Bは非負です。過去を条件とした平均は、

{(1+λ) + (1−λ)}/2 = 1

です。初めの記録をK0 = 1とし、t回までの係数を掛け合わせた値をKtとすると、過去を条件としたKtの期待値はK(t−1)です。これは非負マルチンゲールの例です。係数の条件付き期待値が1以下の場合には、非負スーパーマルチンゲールになります。<a id="cite-50"></a>[[50]](19_references.md#ref-50)

次に、記録が初めて20以上になった時点で止めます。ただし、N回までに達しなければN回で止めるものとします。有限の停止時点での記録の期待値は1以下です。20へ達した道筋では止めた値が20以上、他の道筋でも0以上なので、

20 × P(N回までに20以上になる) ≤ 1

となります。両辺を20で割れば、確率は1/20、すなわち5%以下です。Nを増やした事象の極限を取れば、いつか20以上になる確率についても同じ上限が残ります。これが、この例での時間一様な保証です。

検算ではλ = 1/2に固定し、12回の全4,096通りについて、分数のまま値を計算しました。各時点の平均が1であることと、12回までの到達確率が5%以下であることを照合しています。有限の列挙が無限時間の証明に代わるのではなく、上の導出と実装が一致するかを調べたものです。

現実のデータで使うなら、条件付きの仮説が成り立つか、係数を未来の結果を見ずに選んだか、途中の選択も保証に含まれるかを確かめます。小さな値が出たことは、一般には仮説が正しい証明になりません。

## E 順位から作る90%の予測区間

**ここでわかること：交換可能性の下では、誤差の順位から、分布全体についての被覆を導けます。**

訓練を済ませた予測関数fを固定します。九つの校正例と、新しい一例について、絶対誤差を、

Si = |Yi − f(Xi)|

とします。これら十個の誤差が交換可能で、同点がないと仮定します。交換可能性により、新しい一例が十個の中で何番目になるかは、十通りに均等です。

九つの校正誤差の最大値をqとし、新しい予測値の左右にqを取った区間を作ります。外れるのは、新しい誤差が十個全体の最大になった場合です。その確率は1/10なので、含まれる確率は9/10です。同点を含む場合、この最大値を使う規則では、被覆は少なくとも9/10になります。

この確率は、校正例も新しい例も含む分布についての周辺被覆です。手元の特定の九例を固定した後、すべての入力で90%になるとは主張していません。区間の狭さの保証でもありません。

また、同じデータで予測関数を都合よく合わせ、校正誤差を小さくした場合、ここで置いた対称性はそのまま使えません。訓練と校正の分離を含め、採用する方法の前提に従う必要があります。時系列を切り分けるだけで交換可能性が自動的に成立するとも言えません。<a id="cite-51"></a>[[51]](19_references.md#ref-51)

## F ばねの周期とエネルギー

**ここでわかること：仮定した運動方程式から、周期と保存を、一段ずつ導けます。**

m、kを正の定数とし、摩擦と外力を除き、ばねの力を−kxとします。x = A cos(ωt+φ)を二回微分すると、d²x/dt² = −ω²xです。運動方程式m d²x/dt² = −kxへ代入すれば、ω² = k/mが必要です。cosの位相が2π増える時間が周期なので、T = 2π/ω = 2π√(m/k)となります。

次元も確かめられます。kの単位はニュートン毎メートル、すなわちキログラム毎秒二乗です。m/kの次元は秒二乗、その平方根は秒です。2πには次元がありません。周期の次元と一致します。

E = mv²/2+kx²/2については、m、kが時間で変わらないので、

dE/dt = mv dv/dt + kx dx/dt

= v(m d²x/dt² + kx)

= 0

となります。摩擦−cvを加える場合は、最後の括弧が−cvになり、dE/dt = −cv²です。cが0以上なら、減少または一定となります。

この証明は、置いた模型の中での関係です。現実のばねについては、mとkの変化、摩擦、ばね自体の質量、力の非線形性などが無視できるかを、別に調べます。

## G 集計の反転を確かめる

**ここでわかること：比較する集団の構成を揃えると、合計だけでは見えない関係を確認できます。因果的な解釈には、さらに仮定が要ります。**

第16章の架空の表では、使う群の成功数は8+18 = 26、人数は10+90 = 100です。使わない群は63+1 = 64、人数は90+10 = 100です。合計の差は26%−64% = −38ポイントです。

各課題の構成を半分ずつに標準化すると、使う群は0.5×0.8+0.5×0.2 = 0.5、使わない群は0.5×0.7+0.5×0.1 = 0.4です。差は+10ポイントとなります。

潜在的な結果をY(a)、介入前の課題の種類をL、実際の介入をAとします。一致性、Lを条件とした交換可能性、正値性など、適切な識別の条件が成立するなら、標準化の式、

E[Y(a)] = Σl E[Y｜A=a, L=l] P(L=l)

によって、対象集団での平均的な介入結果を、観測される量へ結びつけられます。<a id="cite-56"></a>[[56]](19_references.md#ref-56) 条件が成立するかは、この計算だけからはわかりません。

## H 量子の問いを、四つの相関で比べる

**ここでわかること：局所的な結果を同じ隠れた変数で表す模型には、相関の組合せに限界があります。量子論は、その限界を超える予測を出します。**

二地点で、それぞれ測定の設定を0か1から選び、結果を+1か−1として記録します。共通の隠れた変数λを与えたとき、一地点の結果は自分の設定だけに依存し、相手の設定には依存しないとします。結果をA0、A1、B0、B1と書きます。ここではまず、λを与えると結果が決まる形を考えます。

一つのλについて、

Sλ = A0 B0 + A0 B1 + A1 B0 − A1 B1

= A0(B0+B1) + A1(B0−B1)

です。B0とB1が同符号なら、二つ目の括弧は0、初めの括弧は+2か−2です。異符号なら、初めの括弧が0で、二つ目が+2か−2です。Aも±1なので、いずれもSλは+2か−2になります。

設定の選択によってλの分布が変わらないという条件の下で、同じ分布について平均します。相関をEab = 平均[Aa Bb]と書けば、

**|E00 + E01 + E10 − E11| ≤ 2**

となります。これがCHSH不等式の一つの書き方です。<a id="cite-61"></a>[[61]](19_references.md#ref-61) 確率的な局所模型も、必要な局所の乱数を含めて同様の形で扱えます。局所的な分解や、設定と隠れた変数の独立性など、ここで置いた条件が論証に関わります。

一方、スピン一重項の量子予測では、単位ベクトルa、bの方向を測った相関は−a・bです。直交する単位ベクトルx、zを用い、a0 = z、a1 = x、b0 = (z+x)/√2、b1 = (z−x)/√2と置くと、三つの相関は−1/√2、最後のE11は+1/√2です。その組合せの絶対値は、2√2 ≈ 2.828となります。

この計算だけでは、現実に量子予測が出たことにはなりません。二つの予測が分かれる場所を示したので、測定を設計できます。測定の抜け、二地点の分離、設定の選択、有限の標本での検定などが、実験の仕事になります。<a id="cite-12"></a>[[12]](19_references.md#ref-12) 何が仮定で、何が数学で、何が観測かをつなげて読むための例です。

## I 一ビットと、熱の下限

**ここでわかること：対称な古典的記憶を完全に消去する標準的な設定では、記憶のエントロピー減少と、熱浴の収支を結びつけられます。**

初めは0と1が確率1/2ずつで、他の系との相関はないものとします。この記憶のエントロピーは、

S初 = −kB{(1/2)ln(1/2) + (1/2)ln(1/2)} = kB ln 2

です。完全に0へ揃えた後は、論理状態の不確かさがなくなり、この部分のエントロピーは0になります。したがって変化は−kB ln 2です。

対称な記憶の構造を元へ戻す等温の操作で、温度Tの熱浴へQの熱を捨てる標準的な模型では、熱浴のエントロピー変化はQ/Tです。全体のエントロピーが減らない条件を用いれば、

−kB ln 2 + Q/T ≥ 0

なので、平均としてQ ≥ kB T ln 2が得られます。kB = 1.380649×10⁻²³ジュール毎ケルビン、T = 300ケルビンを代入すると、約2.871×10⁻²¹ジュールです。<a id="cite-24"></a>[[24]](19_references.md#ref-24)<a id="cite-58"></a>[[58]](19_references.md#ref-58)<a id="cite-63"></a>[[63]](19_references.md#ref-63)

ここでは、消去の失敗を許す場合、初めの確率が偏る場合、他の系との相関を使う場合、量子記憶の場合を一つの式で済ませていません。また、小さな系の一回ごとの揺らぎと、多数回での平均を区別します。操作を十分ゆっくり行う極限で下限へ近づくことと、有限の時間で同じ性能を達成することも、別の問題です。<a id="cite-25"></a>[[25]](19_references.md#ref-25)[[63]](19_references.md#ref-63)
