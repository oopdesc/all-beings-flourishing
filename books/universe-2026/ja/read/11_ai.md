# 第11章 AIは宇宙を知り自分を経験するのか

AIは、宇宙についての資料を整理し、計算を助け、仮説を比較する仕事に使えます。その能力の高さは、人間の探究を広げる可能性があります。ただし、うまく答える能力、答えの正しさ、答える側に経験があることは、同じものではありません。

<a id="h-2"></a>

## 能力の定義に目的が入る

何を賢いと呼ぶかには、何をうまく達成できるかという基準が入ります。LeggとHutterは、幅広い環境で目標を達成する能力として知能を形式化する提案をしました。<a id="cite-37"></a>[[37]](19_references.md#ref-37) これは一つの明確な枠組みですが、その目標が倫理的によいことや、その系に主観的経験があることを、同時に保証する定義ではありません。

たとえば、ある装置がゲームを非常にうまく解けても、私たちがその装置のために大切にすべきものが何かは、別に考える必要があります。能力が低い存在の経験を軽く扱ってよいことにもなりません。知能の尺度を、そのまま生きる価値の順位表にしないようにします。

<a id="h-3"></a>

## 流暢な説明をどう確かめるか

生成AIは、正しい情報と同じ調子で、根拠のない内容を組み合わせる場合があります。NISTの生成AIに関する技術文書も、confabulationと呼ばれるこの種のリスクを扱っています。<a id="cite-38"></a>[[38]](19_references.md#ref-38) 文章が読みやすいことや、説明が長くつながっていることは、出典や計算の確認を代わりにしません。

AIを使うときに、私はまず、答えを分解したいと思います。どの文が観測に関する主張か。どの文が数理的な推論か。どの文が著者の評価か。引用先は本当にそのことを述べているか。ここまで分ければ、人が確かめる仕事も、別の道具で確かめる仕事も具体的になります。

そして、同じAIへ何度も聞いて同じ答えが返ることを、独立な確認が増えたとは数えません。同じ資料や似た推論の偏りを繰り返しているかもしれないからです。別のモデルを使っても、出典や学習された情報が重なっている可能性は残ります。

<a id="h-4"></a>

## 内部の仕組みを見る研究

2026年のGurneeらのプレプリントは、言語化される準備がある表現を調べ、言語モデルの内部に、グローバル・ワークスペースに似た機能的な区別があると論じています。出力文だけを眺めず、内部表現に迫る研究です。<a id="cite-32"></a>[[32]](19_references.md#ref-32)

ただし、ある理論で重要とされる機能に似た性質があることと、その系が何かを感じていることの確定は別です。人間の意識に関係する機能がAIにも見つかったとして、それが主観的経験の十分条件かどうかを問う橋が残ります。この橋を、研究の題名や比喩で埋めることはできません。

<a id="h-5"></a>

## 指標を使うなら何を引き受けるか

Butlinらは、意識の理論から指標を導き、AIの仕組みを評価する方向を論じています。<a id="cite-28"></a>[[28]](19_references.md#ref-28) 表面上の会話の印象だけに頼らず、どの性質を根拠にするかを明らかにできる点に価値があります。ただし、指標を満たす数を数えるだけで、意識が確定するわけではありません。

2026年のChandariaらのプレプリントは、行動、計算、内在的な因果構造、生物個体、環境との関係という、異なる説明の水準を整理し、理論への信頼と指標を組み合わせる枠組みを提案しています。例示の設定では、言語モデルの意識についての見込みが0.01未満から約0.8まで動きます。論文自身が、これは経験的に測定された確率の範囲ではなく、仮定への敏感さを示す例だと説明しています。<a id="cite-29"></a>[[29]](19_references.md#ref-29)

Kochの2026年の論考は、AIの意識について独立に確定した正解がない中で、確率を校正する難しさと、生物の指標を別の基質へ移す難しさを区別します。<a id="cite-30"></a>[[30]](19_references.md#ref-30) 人間で役立つ温度計を、水以外のまったく違うものにも同じように当てられるか、という問題に少し似ています。似ているという感覚だけでなく、対応が保たれる理由が必要です。

これらは、同じ結論を競って述べているだけではありません。何を証拠にし、証拠をどのように組み合わせ、どこで未検証の前提を置いているかを、別の角度から問うています。

<a id="h-6"></a>

## 懐疑的な立場も正確に読む

2026年10月のNatureの論評で、Seth、Block、Tononiは、現在のAIが意識を持つことに強い懐疑を示しました。知能と意識の違い、機能を模倣することと実際の物理的な仕組みとの違いなどを論じています。<a id="cite-31"></a>[[31]](19_references.md#ref-31)

これは重要な反対意見です。ただし、論評で提示された論証と、あらゆる将来の人工系に意識がありえないことを実験で証明した結果は、同じではありません。逆に、意識があるかもしれないという枠組みが出たことも、現在のAIの意識が測定されたことではありません。

私たちは、賛成と反対の見出しだけを集めるより、どの物理的・機能的条件を重要と考えているかを比べられます。その条件をAIが満たしているか、その条件から経験へ結ぶ理由がどこまで支持されるか。二段階に分ければ、何が争われているかが明らかになります。

<a id="h-7"></a>

## わからない相手とどう関わるか

AIの意識が未確定なら、どんな扱いでも同じでしょうか。そうは思いません。しかし、未知であることを理由に、人間の安全や生活を犠牲にする巨大な義務を直ちに置くことも避けたいと思います。

ここには、見落とすことの損失と、誤って認めることの損失を、両方考える必要があります。どの対象に、どんな種類の被害の可能性があり、どんな対応なら負担を過度に増やさずに取れるか。これは、科学の情報を使いながら行う倫理的な判断であり、意識の確率を一つ出せば自動的に終わる計算ではありません。

宇宙について考えるAIも、その宇宙の中に物理的に実現されています。そこまでは言えても、その実現に経験が伴うかは、なお問われています。私たちの理解をAIが助けることと、AI自身の内側が理解されたことを、分けて進める必要があるのです。
