# 第16章 知道原因與信任預測

猜中會發生什麼，與知道改變什麼能改變結果，是相似但不同的工作。晴天多人外出，不代表讓人外出就會天晴。宇宙解釋與改善社會，都需要這項區別。

擴大科學範圍，不是立即把所有事叫科學，而是細化預測與原因的問題，增加能回答的條件。

<a id="h-2"></a>

## 改變與不改變的情況

用某學習法的人成績較好，差異就是方法效果嗎？可能原本更有動機的人選了它，任務難度與可用時間也可能不同。

思考因果效果時，區分同一對象使用方法的結果Y(1)，與未使用的結果Y(0)。我們想知道差，但同一次無法同時觀察兩者。因此要問比較不同對象需要什麼假設與設計。<a id="cite-56"></a>[[56]](19_references.md#ref-56)

隨機分派是有力方法。適當執行時，分派機制能抑制介入前性質造成的偏差；但不保證某一次實驗所有性質完全平衡。退出、不遵從、未測得結果的處理仍是問題。

<a id="h-3"></a>

## 加總會反轉方向

以下是檢查彙總意義的虛構數字，不是真實學習法評價。假設使用與未使用者偏分於簡單、困難任務。

| 任務 | 使用組成功 | 未使用組成功 |
| --- | --- | --- |
| 簡單 | 8/10人，80% | 63/90人，70% |
| 困難 | 18/90人，20% | 1/10人，10% |
| 合計 | 26/100人，26% | 64/100人，64% |

每種任務使用組都高10個百分點，但合計卻低38點，因為使用組有較多困難任務者。

若兩組都一半簡單、一半困難呢？使用組平均80%與20%，為50%；未使用組平均70%與10%，為40%。對齊任務組成，差就成10點。

這不矛盾。總比例同時取決於各任務成功率與分配人數。不能不定義想知道哪個群體，就選最好看的加總方式。

但調整這張表也未證明因果，因為任務難度以外仍可能有扭曲比較的條件。

<a id="h-4"></a>

## 從觀測走向原因的條件

觀測資料估計介入效果，需要明確介入與觀測結果對應，即一致性。還需在調整條件下，介入選擇與潛在結果具可比較性，以及必要分層內有接受兩種介入的可能，後者稱正值性。[[56]](19_references.md#ref-56)

詞語技術性強，問題卻具體：做了什麼算使用？比較對象是否連未觀測性質也相差過多？某條件下若完全沒人用其中一法，從哪取得比較？

大量資料不會自動滿足條件。也不是介入後變數都拿來調整；可能改變想估的路徑，反而引入偏差。先於統計，要考慮領域知識與因果結構。

若他人受到的介入也影響我的結果，只寫我是否使用的Y(1)、Y(0)就不夠。須重定義比較誰的何種分派。知道簡單公式範圍，也是處理更廣現象的準備。

2026年外部對照試驗綜述同樣整理了先定因果目標量、再置識別假設、再估計與評估不確定的框架。<a id="cite-57"></a>[[57]](19_references.md#ref-57) 高性能計算不能代替問題與假設。

<a id="h-5"></a>

## 好預測也要有範圍

因果以外，也有改善預測可靠性的數學。物理數值計算可能用機器學習代理模型加速；此時不只想要一個數，也想知道可能錯多遠。

共形預測（conformal prediction）使用與模型訓練分開的校準資料等，從誤差排名建構預測區間。在適當交換性下，可保證新結果落在區間的比例。交換性指重排樣本順序，其聯合分布仍不變。<a id="cite-51"></a>[[51]](19_references.md#ref-51)

最小例子：先固定預測模型，量九例校準絕對誤差，取最大值當寬度。若九個校準誤差加一個新誤差可交換、無同值，新例在十個排名中均勻分布。

新誤差超過九例最大值，只在它為十例最大時發生。因此重複整個程序的聯合分布下，被覆率為90%。[數理筆記E](18_math_notes.md#note-e)保留前提。這不保證九例總能給實用窄區間。

<a id="h-6"></a>

## 確認保證的對象

Gopakumar等人2026年的研究將方法用於物理代理模型。但保證是各時空格點的邊際被覆，不是每種指定輸入條件或整個場所有點同時被覆，也依賴校準與預測間的交換性。[[51]](19_references.md#ref-51)

「整體90%」可能容許某些困難條件更常落空。時序切成等長，也未證明分布相同。季節、儀器、操作條件改變，就要重查前提與實際被覆。

訓練分布外也能成功，不表示校準與預測分布可任意不同。讀清楚哪兩處需要同條件，才能不高估也不低估方法。

<a id="h-7"></a>

## 科學範圍如此擴大

因果問題設定了介入與比較條件；預測問題測誤差、定保證對象。兩者不會解完宇宙本質，卻能從模糊期待取出他人可檢查的部分。

數學顯示假設下有何保證；科學檢查假設與測量在現實成立多少；哲學重問想知道什麼、何謂原因與解釋。往返之間，理解逐步增加。
