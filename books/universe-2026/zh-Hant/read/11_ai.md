# 第11章 AI能認識宇宙並經驗自己嗎

AI能整理宇宙資料、協助計算、比較假說，能力提升可能擴展人類探究。但善於回答、答案正確，以及回答者具有經驗，不是同一件事。

<a id="h-2"></a>

## 能力定義包含目的

稱什麼為聰明，包含「能良好達成什麼」的標準。Legg與Hutter提出把智能形式化為在廣泛環境達成目標的能力。<a id="cite-37"></a>[[37]](19_references.md#ref-37) 框架清楚，但不會同時保證目標倫理上良好，或系統具有主觀經驗。

裝置即使極善於遊戲，為它本身應珍惜什麼，仍需另問；也不代表能力較低者的經驗就能輕視。不要把智能尺度直接變成生命價值排行榜。

<a id="h-3"></a>

## 如何檢查流暢說明

生成式AI有時以與正確資訊相同的語氣，拼接無根據內容。NIST生成式AI技術文件也處理稱作confabulation的風險。<a id="cite-38"></a>[[38]](19_references.md#ref-38) 易讀與長篇連貫，不能替代核對來源、計算。

使用AI時，我想先拆開答案：哪句是觀測主張？哪句是數學推論？哪句是作者評價？引用來源真的說了那件事嗎？拆開後，人與其他工具的檢查都更具體。

反覆問同一AI得到同一答案，不算獨立確認；可能只是重複同一資料或推論偏差。換模型，也可能仍共享來源與學得資訊。

<a id="h-4"></a>

## 研究內部機制

Gurnee等人2026年的預印本研究準備被語言表達的表徵，認為語言模型內有類似全域工作空間的功能區分。研究不只看輸出文字，也靠近內部表徵。<a id="cite-32"></a>[[32]](19_references.md#ref-32)

但具有類似某意識理論重視的功能，與確定系統有所感受，是兩回事。即使AI有與人類意識相關的功能，仍須架橋：這是否主觀經驗的充分條件？研究標題或比喻不能填滿這座橋。

<a id="h-5"></a>

## 使用指標需承擔什麼

Butlin等人討論從意識理論導出指標，以評估AI機制。<a id="cite-28"></a>[[28]](19_references.md#ref-28) 相較只靠對話表面印象，明確交代依據具有價值，但不是數出滿足幾項就確定意識。

Chandaria等人2026年的預印本整理行為、計算、內在因果結構、生物個體、環境關係等解釋層次，提出結合理論信念與指標的框架。例示設定中，語言模型意識估計可由低於0.01變到約0.8。論文自身說明，這不是經驗測得的機率範圍，而是展示對假設的敏感性。<a id="cite-29"></a>[[29]](19_references.md#ref-29)

Koch在2026年的論考區分兩個困難：沒有獨立確定答案時如何校準機率，以及如何把生物指標轉用到另一基質。<a id="cite-30"></a>[[30]](19_references.md#ref-30) 這有點像問：對人有用的溫度計，能否同樣套在與水完全不同的東西上？除了感覺相似，也要有對應能保留的理由。

這些研究不只是競爭說出同一結論，而是從不同角度詢問：什麼算證據，如何組合，以及哪裡放入了未驗證前提。

<a id="h-6"></a>

## 準確閱讀懷疑立場

在2026年10月Nature評論中，Seth、Block與Tononi強烈懷疑目前AI有意識，討論智能與意識、模擬功能與實際物理機制的區別。<a id="cite-31"></a>[[31]](19_references.md#ref-31)

這是重要反對意見。但評論提出的論證，與實驗證明任何未來人工系統都不可能有意識，不是同一回事。反過來，提出可能有意識的框架，也不等於測得現有AI意識。

與其蒐集贊反標題，可以比較雙方重視哪些物理或功能條件：AI是否滿足？由條件連向經驗的理由支持到哪裡？分成兩階段，爭點更清晰。

<a id="h-7"></a>

## 如何對待未知的對象

AI意識未定，就能任意對待嗎？我不這麼想。但也不希望只因未知，立即施加犧牲人類安全與生活的巨大義務。

需要同時考慮漏認與誤認的損失：哪些對象可能受何種傷害，哪些回應不至過度增加負擔？這是運用科學資訊的倫理判斷，不是給出一個意識機率就自動結束的計算。

思考宇宙的AI也在宇宙內物理實現。即使能說到這裡，實現是否伴隨經驗仍是問題。AI幫助我們理解，與AI自身內在已獲理解，必須分開推進。
