# 第9章 從微小定律走向宏大世界

若知道宇宙根本定律，就能立即理解生命、心智與社會的一切嗎？至少，知道基礎描述，與能解釋並預測複雜現象，不是同一回事。從日常到宇宙，我們使用適合不同尺度的語言。

<a id="h-2"></a>

## 地圖不必只有一張

想像地圖。步行需要人行道路圖；思考大陸移動，這張圖就不夠合適。不是哪張是假圖，而是依問題保留不同資訊。

物理描述也一樣。逐一列出所有粒子運動，與使用溫度、壓力不同。後者減少細節，卻不因此變成脫離現實、毫無用處的詞語。有時正因省略細節，才找到可穩定使用的關係。

Anderson的〈More Is Different〉認為，多元素系統具有新的性質與解釋層次，不是知道基礎定律就已足夠。<a id="cite-26"></a>[[26]](19_references.md#ref-26) 不必把它讀成複雜事物不遵守物理；遵守定律，與基礎方程已窮盡所需解釋，仍可區分。

<a id="h-3"></a>

## 不要停在「湧現」一詞

湧現通常指：只看個別元素難以掌握的性質，在整體結構與交互作用中出現。但說它湧現，還沒有解釋產生機制。

例如，可以說群體合作湧現了，但誰與誰交換資訊、哪些條件抑制背叛、合作在哪裡瓦解，仍須調查。同樣，說意識是湧現，也未回答哪些結構或變化與主觀經驗相關。

可再具體追問四件事：元素是什麼？如何交互作用？整體測量什麼量？條件改變時什麼會變？若逐步回答，湧現便成為標示待解釋位置的路標。

<a id="h-4"></a>

## 理解生命所需的區分

生命包含代謝、自我維持、繁殖、演化等特徵。未必能在所有情況，用一條短定義劃清邊界。但只要明確指出研究哪項特徵，具體研究仍能前進。

承認生命是物理過程，不必認為活著的一切解釋已完成。具有自我維持機制，也不能立即推出系統有痛苦或喜悅。生命、意識、智能可能相關，卻不是同義詞。

把宇宙本身稱作生命時，這項區分也很重要。星辰誕生消逝、結構改變，可能讓人感到像生命；但混合生命比喻與生物學上可檢驗的性質，就看不清該確認什麼。

<a id="h-5"></a>

## 無法預測不等於沒有定律

複雜系統中，初始條件的微小差異，可能放大成後來的巨大差異。蒐集必要資訊或完成計算本身，也可能現實上極難。

這不能推出沒有定律；反過來，有定律也不保證完全可預測。障礙來自資訊不足、計算困難、模型錯誤，還是原理性質，會影響下一步該試什麼。

智能提升能幫助找到好近似、篩選必要測量、連接不同尺度描述。但期待更聰明就能消除所有物理限制，是另一個跳躍。能力進步不等於可能性無限。

<a id="h-6"></a>

## 在整體中看見意義

無數交互作用中，星辰、細胞、語言與提問出現。這段連續過程本身已足夠令人驚嘆。不必為了維持驚奇，就附加「宇宙由單一意志使自己成長」作為科學事實。

可以把這種觀點當哲學思考，討論它比既有解釋多說明什麼，又承擔哪些新難題。但只憑演化或複雜化的觀測，無法確定宇宙的道德進步。

不必賦予宇宙特殊意志，也能說我們是宇宙的一部分，並且正在思考宇宙。再說「宇宙認識自己」，取決於「自己」的意思。我希望讓有詩意的表達與已實證的機制，各自在其位置發揮作用。
