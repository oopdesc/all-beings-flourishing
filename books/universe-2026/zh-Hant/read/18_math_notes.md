本節保留計算中間步驟，均為本書設定的例子，不是既有研究原始資料重新分析，也不主張新數學定理。手算之外，用短程式核對有限例子與數值，未使用形式證明輔助系統。

## A 通過同一觀測的不同解釋

**這裡能知道什麼：符合有限觀測點，不一定決定後續唯一預測。**

令f(x) = x，g(x) = x + x(x−1)(x−2)。

x為0、1、2時，新增乘積至少一因子為0，故三點相同。但x為3時：

f(3) = 3

g(3) = 3 + 3×2×1 = 9

所以三點一致推不出所有x一致，還需觀測或函數限制。

這不是所有物理理論同價的證明。物理還比較其他觀測、對稱性、獨立預測與適用範圍。本例反駁的是只靠擬合就結束論證。

## B 不要反轉條件

**這裡能知道什麼：敏感度99%，不保證陽性有99%是真的。**

第12章虛構判定器中，H為真信號，D為判陽性。

P(H) = 0.001

P(D｜H) = 0.99

P(D｜非H) = 0.01

同時真且陽性的機率為0.001×0.99 = 0.00099。非真且陽性為0.999×0.01 = 0.00999。兩者互斥，P(D)合計0.01098。

因此P(H｜D) = 0.00099/0.01098 = 11/122 ≈ 0.09016。

母群頻率改，答案也改。這不是對真實偵測器或疾病的估計。

## C 區分擬合與貝氏因子

**這裡能知道什麼：最佳擬合相同，先驗允許範圍仍會改變整體模型比較。**

觀測x遵從平均μ、標準差1的常態模型，結果x = 3。標準常態密度寫φ，累積分布寫Φ。

H0固定μ = 0，觀測密度為φ(3)。

H1令μ先驗均勻分布於−a至a，a大於3並事前決定。最佳μ = 3，最大概似比為：

φ(0)/φ(3) = exp(9/2) ≈ 90.017

H1邊際概似是對μ平均密度：

m1(3) = {Φ(a−3) − Φ(−a−3)}/(2a)

H1對H0的貝氏因子為B10 = m1(3)/φ(3)。

| a | 最大概似比 | 貝氏因子B10 |
| --- | --- | --- |
| 5 | 約90.017 | 約22.051 |
| 50 | 約90.017 | 約2.256 |
| 500 | 約90.017 | 約0.226 |

權重分給不合觀測的區域，平均便改變。若再放H1、H0本身的先驗機率，可用貝氏因子得後驗勝算。因子本身不叫H1為真的機率。

這不是重現真實宇宙論數字，只抽出第4章不同比較尺度的機制。

## D 允許逐序查看的條件

**這裡能知道什麼：符合條件的非負記錄，包含中途停止，也能限制出現大值的機率。**

假設每次即使給定過去，正反面仍各1/2。正面X = 1，反面X = 0。結果揭曉前選−1至1的λ，每次乘數為：

B = 1 + λ(2X−1)

B非負，條件平均為：

{(1+λ) + (1−λ)}/2 = 1

初值K0 = 1，Kt為至t次乘積。給定過去，Kt期望為K(t−1)，是非負鞅。若乘數條件期望不超過1，則為非負上鞅。<a id="cite-50"></a>[[50]](19_references.md#ref-50)

首次記錄達20以上就停，若N次仍未達則於N停。有限停止時刻的期望不超過1。到20的路徑值至少20，其餘非負，因此：

20 × P(N次內至少達20) ≤ 1

除20得上限1/20，即5%。對N增大的遞增事件取極限，總有一天達20的機率仍有相同上限，這是時間一致保證。

檢算固定λ = 1/2，以精確分數列舉12次全部4,096路徑，核對各時點平均1與12次內到達機率不超過5%。有限列舉不代替無限時間證明，只檢查導出與實作相合。

用於現實，要確認條件假說、乘數未偷看未來、中途選擇也納入保證。小值一般不證明假說正確。

## E 用排名做90%預測區間

**這裡能知道什麼：交換性下，誤差排名能導出聯合分布上的被覆。**

固定訓練完成的函數f，九個校準例與一個新例的絕對誤差為：

Si = |Yi − f(Xi)|

假設十個誤差可交換且無同值，新例排名便在十位均勻。

取九個校準誤差最大值q，在新預測左右各取q。只有新誤差是十例最大才落空，機率1/10，因此被覆9/10。有同值時，此最大值規則至少被覆9/10。

這是含校準與新例的聯合分布之邊際被覆，不主張固定手上九例後，每種輸入都有90%，也不保證窄區間。

若同資料調f以壓低校準誤差，這裡的對稱未必保留。須遵守方法前提，包括訓練與校準分開。只切割時序也不自動保證交換性。<a id="cite-51"></a>[[51]](19_references.md#ref-51)

## F 彈簧週期與能量

**這裡能知道什麼：由假設的運動方程，逐步導出週期與守恆。**

m、k為正定數，無摩擦外力，力為−kx。x = A cos(ωt+φ)兩次微分得d²x/dt² = −ω²x。代入m d²x/dt² = −kx，需ω² = k/m。相位增2π所需時間為T = 2π/ω = 2π√(m/k)。

量綱也吻合。k單位牛頓每公尺，即公斤每秒平方。m/k為秒平方，平方根是秒，2π無量綱。

對E = mv²/2+kx²/2，m、k不隨時間變，所以：

dE/dt = mv dv/dt + kx dx/dt

= v(m d²x/dt² + kx)

= 0

加摩擦−cv，最後括號為−cv，故dE/dt = −cv²。c非負時，減少或不變。

這是模型內證明。真彈簧仍要另查m、k變動、摩擦、彈簧自身質量、力的非線性等是否可忽略。

## G 檢查加總反轉

**這裡能知道什麼：對齊群體組成，可確認總數看不出的關係；因果詮釋還需假設。**

第16章虛構使用組成功8+18 = 26，總數10+90 = 100；未使用組成功63+1 = 64，總數90+10 = 100。總差26%−64% = −38點。

各任務各半標準化，使用組0.5×0.8+0.5×0.2 = 0.5，未使用組0.5×0.7+0.5×0.1 = 0.4，差+10點。

令潛在結果Y(a)、介入前任務類型L、實際介入A。在一致性、給定L的交換性、正值性等適當識別條件下，標準化式為：

E[Y(a)] = Σl E[Y｜A=a, L=l] P(L=l)

它把目標群體的平均介入結果連到觀測量。<a id="cite-56"></a>[[56]](19_references.md#ref-56) 計算本身不會確認條件成立。

## H 用四個相關比較量子問題

**這裡能知道什麼：以同一隱變量表示局域結果的模型，其相關組合有上限；量子預測可超過。**

兩地各選設定0或1，結果記+1或−1。給定共同隱變量λ，一地結果只依自己的設定，不依對方。記A0、A1、B0、B1，先考慮λ決定結果的形式。

對單一λ：

Sλ = A0 B0 + A0 B1 + A1 B0 − A1 B1

= A0(B0+B1) + A1(B0−B1)

B0、B1同號時，後括號0、前括號±2；異號時前0、後±2。A也是±1，故Sλ始終±2。

假設λ分布不隨設定選擇改變，對同分布取平均。令Eab = 平均[Aa Bb]，得到：

**|E00 + E01 + E10 − E11| ≤ 2**

這是CHSH不等式的一種形式。<a id="cite-61"></a>[[61]](19_references.md#ref-61) 隨機局域模型可把必要局域亂數納入相似形式。局域分解、設定與隱變量獨立，都是論證條件。

量子自旋單重態在單位方向a、b的相關為−a·b。取正交單位向量x、z，令a0 = z、a1 = x、b0 = (z+x)/√2、b1 = (z−x)/√2，三個相關為−1/√2，E11為+1/√2。組合絕對值為2√2 ≈ 2.828。

此計算不等於現實觀測已發生；它指出預測分歧處，讓測量可設計。偵測漏洞、兩地分離、設定選擇、有限樣本檢定，是實驗的工作。<a id="cite-12"></a>[[12]](19_references.md#ref-12) 本例連接並區分假設、數學與觀測。

## I 一位元與熱下限

**這裡能知道什麼：對稱古典記憶完全抹除的標準設定，可連接記憶熵減與熱浴收支。**

初始0、1各1/2，與他系無相關。記憶熵為：

S初 = −kB{(1/2)ln(1/2) + (1/2)ln(1/2)} = kB ln 2

完全歸0後，邏輯狀態不確定消失，此部分熵為0，變化−kB ln 2。

恢復對稱記憶結構的等溫操作中，向溫度T熱浴排Q熱的標準模型，熱浴熵變為Q/T。總熵不減要求：

−kB ln 2 + Q/T ≥ 0

故平均Q ≥ kB T ln 2。代kB = 1.380649×10⁻²³焦耳每克耳文、T = 300克耳文，約得2.871×10⁻²¹焦耳。<a id="cite-24"></a>[[24]](19_references.md#ref-24)<a id="cite-58"></a>[[58]](19_references.md#ref-58)<a id="cite-63"></a>[[63]](19_references.md#ref-63)

這個單式不包辦抹除失敗、初始偏態、利用他系相關、量子記憶等情形。微小系統單次漲落與多次平均也不同。足夠慢的極限接近下限，與有限時間達成同性能，同樣是不同問題。<a id="cite-25"></a>[[25]](19_references.md#ref-25)[[63]](19_references.md#ref-63)
