# 第3章 如何確認看不見的物質

暗物質的問題，並不是什麼看不見的東西都能拿來解釋，而是一種說明能在多大範圍內涵蓋觀測到的運動、光線彎曲等現象。由重力推知的質量分布，與發光物質分布不一致，一直是重要線索。

<a id="h-2"></a>

## 同時解釋多種觀測

研究星系旋轉，與研究星系團周圍的光如何彎曲，並非用同一部儀器測量同一個量。還要加上背景輻射與大尺度天體分布的限制。好的解釋必須回應這些不同條件，而非只解釋一個令人印象深刻的現象。

對於稱作子彈星系團的碰撞星系團，Clowe等人報告了X射線所顯示的高溫氣體，與重力透鏡所推知的質量分布之間的偏移。這有力支持：僅靠包含大量普通物質的氣體位置，無法解釋重力分布。但它並未指出暗物質是哪一種粒子。<a id="cite-3"></a>[[3]](19_references.md#ref-3)

區分「某物存在的證據」與「對某物的完整解釋」，便能看出研究的位置。即使有多項根據支持不可見質量成分，它是什麼粒子、如何與普通物質交互作用，仍需要另外的觀測。

<a id="h-3"></a>

## 在地下等待的實驗

若暗物質候選粒子會罕見地與普通物質交互作用，我們也許能在地球上尋找痕跡。實驗於是壓低宇宙射線等背景，準備性質已知的偵測器，尋找候選反應。

沒有找到的結果也有資訊，但不是證明所有暗物質都不存在。它縮小的是：在所假設的粒子質量與交互作用強度組合中，實驗本來應該看見的範圍。釐清搜尋過哪裡，就會改變下一步該查哪裡。

反過來，一個罕見事件也不足以證明候選粒子已被發現。儀器、放射性物質、偶然重疊等普通物理過程仍會產生背景。尋找新事物時，理解背景與發現本身同樣重要。

<a id="h-4"></a>

## 2026年報告的一個事件

LZ合作團隊在2026年9月報告了納入較高反沖能量的搜尋。在2.84噸年的曝光量分析中，有一個與約248 keV核反沖相容的事件。論文考慮搜尋範圍的廣度後，給出2.6σ的全域顯著性，不能與3.4σ的局部最大值混淆。<a id="cite-4"></a>[[4]](19_references.md#ref-4)

這不是已確認的暗物質發現。論文也檢討罕見背景的可能。該事件來自2023年的資料，2026年是分析發表的時間；閱讀時要區分發表日期與現象發生日期。[[4]](19_references.md#ref-4)

我們能帶走什麼？首先，搜尋與以往不同的範圍，可能出現需要研究的新事件。其次，看到罕見事件的喜悅之後，原因的辨別仍未結束。新穎是推動研究的理由，卻不能代替確定答案所需的證據。

<a id="h-5"></a>

## 顯著性不是身分的機率

2.6σ不能改讀成「它有99%以上機率是暗物質」。檢定評估的是：在指定背景模型下，得到這麼罕見資料的程度。它不是比較所有候選解釋後，直接測量暗物質假說的機率。

若背景模型遺漏了某種過程，罕見程度的評估也會改變。搜尋許多位置與候選對象，也會增加在某處遇到罕見事件的機會。所以必須把搜尋範圍納入評估，再尋求獨立確認。[第12章](12_evidence.md)會用虛構計算例子進一步說明。

<a id="h-6"></a>

## 靠近本質的兩條路

暗物質研究至少有兩條路：解釋天體與整個宇宙的重力行為；在實驗中找到候選粒子的反應並調查性質。未來必須對照兩條路的答案，確認是否指向同一個對象。

修改重力定律的想法，不該只因被視為異端就遭排除。但它同樣必須回答，能否解釋既有框架處理的眾多現象。解決一項不滿，不代表整體比較已結束；本章也無法評估所有替代方案。

不急著走向「看不見所以什麼都行」，也不急著斷言「看不見所以不存在」。若不可見的事物確實存在，它與可見事物的關係中應留下什麼？這種提問對思考意識也有幫助。但能用相同提問方式，不代表暗物質與意識具有相同機制。
